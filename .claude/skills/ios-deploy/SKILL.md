# 배포 범위 제한

루트 AGENTS.md와 사용자 요청이 우선한다. 이 skill의 이름은 업로드 실행 권한을 뜻하지 않는다. 스토어 등록·업로드·테스트 배포·심사 제출·공개는 사용자가 직접 한다. 해당 API·스크립트를 실행하지 않는다.

현재 단계에는 키 입력이나 배포 의존성 설치가 필요 없다. 이후 요청 시 대상 앱의 README·AGENTS·ROADMAP과 apps-deployment의 해당 플랫폼 문서를 읽고 사용자가 할 수동 단계를 안내한다. 전체 환경변수·키·실제 데이터·민감 캡처를 출력하거나 외부로 전달하지 않는다. 자동 commit·push·클라우드 공개를 하지 않는다.
