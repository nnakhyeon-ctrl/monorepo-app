# 공통 지침 참조
최신 8단계는 같은 폴더 AGENTS.md와 docs/SOCIAL-AUTH-RESULTS.md를 따른다. 사용자가 선택한 로컬 우선 범위로 Google/카카오/iOS Apple 코드와 검증·설정 안내를 준비한다. 실제 로그인/운영 적용은 외부 설정 후 검증하며 미연결을 성공 처리하지 않는다. 아래 7단계의 소셜 제한보다 최신 요청을 우선하고 결제/삭제/배포는 진행하지 않는다.

최신 7단계 이메일 흐름은 같은 폴더 AGENTS.md와 docs/EMAIL-AUTH-RESULTS.md를 우선한다. 기존 화면/서버를 재사용하고 기기 기록을 유지한다. 로컬 검증과 실제 메일/복귀/운영 보안 적용을 구분한다. 소셜/결제/삭제/배포는 진행하지 않고 이 단위에서 멈춘다. 아래 이전 단계 설명보다 이 상태를 우선한다.


최신 6단계 인증 백엔드/접근 통제는 같은 폴더 AGENTS.md와 docs/AUTH-BACKEND-RESULTS.md를 우선한다. 로컬 기반/에뮬레이터 결과와 실제 클라우드·로그인 UI/결제 미연결을 구분하고, 이 단계 결과 기록 후 멈춘다.

최신 5단계 미래형 출격 준비는 같은 폴더 AGENTS.md와 docs/LOADOUT-RESULTS.md를 따른다. 이 한 단위 이후에는 별도 사용자 지시를 기다린다.

최신 사용자 메뉴 점검은 docs/MENU-RESULTS.md와 같은 폴더 AGENTS.md를 따른다. 실제 두 기기 협동 검증 전 사용자 메뉴는 숨기고 문의처/정책 URL은 사용자 전달 대기다.

같은 디렉터리의 AGENTS.md와 루트 ../../AGENTS.md를 읽고 따른다. 최신 요청으로 무료 실제 전투·15탄·기기 저장·유료 선택 능력·계정/결제 정책 모델·협동 시험 구현을 진행했다. 현재 구현/미검증 경계는 ROADMAP.md와 docs/PLAYABLE-RESULTS.md를 우선한다. 실제 인증·계정 기록 서버·스토어 결제·두 실기기 협동은 준비/검증 대기이며 성공으로 흉내 내지 않는다. 등록·배포·유료 서비스 가입은 사용자 수행이다.
