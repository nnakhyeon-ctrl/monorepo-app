## 현재 실행 상태

`게임 시작`은 계정/결제 없이 선택한 작전을 실행한다. 실제 무료 기체 이미지, 상대 드래그·자동 사격·보호막, 적/보스, 결과·재도전·순차 해금과 최고 기록이 있다. 첫 전투 조작 안내와 설정의 조작 감도·선택적 기기 통계를 제공한다. 이메일은 7단계 로컬 연결/외부 대기를 구분하며 소셜·삭제·구매/복원은 미연결을 성공으로 표시하지 않는다. 1~3탄 무료 자동 공략은 검증했고 전체 난이도·재미·실기기 검사는 계속 필요하다.

첫 화면 메뉴는 ‘전투기·장비’, ‘환경설정’이며 시작 위에서 작전을 선택한다. 구독 관리·구매 복원·기록 이어하기는 환경설정에 있다. 월간·연간 구독 혜택은 같고 가격은 관리자 확정 대기다. 유효한 이용권이 없는 추가 캐릭터/스킬은 선택할 수 없다. 복원과 계정 기록 동기화는 별개다.

루트 F5 구성 또는 앱 폴더의 `flutter run -d emulator-5554`로 실행한다. 검사 명령은 [실행 기록](docs/PLAYABLE-RESULTS.md)에 있다. 앱별 Dart lockfile과 루트 Node 도구를 분리했다. 협동 참고 서버는 앱의 `server/coop_server.dart`이며 Dart SDK만 사용하고 인증/기록용 Firebase 서버와 구분한다. Mac/iOS 빌드·두 실기기 협동·실제 결제 검증은 미실행이다.

스토어 콘솔·인증/결제 설정·호스팅 공개·유료 플랜 가입은 사용자가 직접 한다. 자동 commit·push·배포는 수행하지 않는다.
