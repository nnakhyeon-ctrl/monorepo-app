## 화면·디자인과 첫 출시 분량

앱 시작/UID별 캐시·서버 상태 확인 → 타이틀 → 무료 기본 출격 또는 구독 전용 구성의 이용권 확인 → 스테이지 → 결과/보상 → 격납고·영구 강화 → 체크포인트 저장/상태 확인 → 재출격이 기본 흐름이다. 같은 UID의 다른 휴대폰은 서버 저장 완료 기록을 불러온다. 미구독자도 무료 기본 구성으로 진행하며 구독 전용 콘텐츠를 선택할 때만 혜택 안내·복원·지원을 제공한다. 설정에서 로그인·기록 동기화/충돌·기기 캐시 삭제/계정 기록 초기화·계정 삭제를 구분한다. 기본 플레이에는 결제가 필요하지 않고 클라우드 이어하기에는 계정 연결이 필요하다.

계정 화면은 흰 배경·검은 제목/기본 버튼·밑줄 입력란·가입/복구 링크·하단 공식 소셜 버튼을 따른다. 게임은 적탄/아군탄/배경 대비·중심 판정·가독성 좋은 HUD·이펙트 완화를 우선한다. 자세한 흐름과 첨부 이미지 분석은 [GAME-DESIGN.md](docs/GAME-DESIGN.md), [VISUAL-UPGRADE.md](docs/VISUAL-UPGRADE.md)에 있다.

4단계 당시 첫 분량은 3스테이지 등이었으나 최신 요청으로 1~3탄 검증 후 15탄 초기 목표로 확장했다. 현재 15탄 무료 자동 시뮬레이션은 모두 성공했고 실제 사용자 밸런스·실기기 검증은 남았다. 계정 기반 서버 저장·다른 휴대폰 이어하기는 첫 출시 목표이며 외부 연동 대기다. 협동은 최신 요청에 따라 시험 개발했지만 두 실기기·운영 결과 정산 검증 전 첫 출시 포함을 권장하지 않는다. 부위 파괴·영구 성장/재화·음악·고급 연출·컨트롤러는 아직 구현 완료가 아니다. 온라인 순위·메모·SNS·AI·광고·자동 유료 전환 체험·유료 재화는 제외한다. 월간/연간 구독은 추가 콘텐츠에만 적용한다.

## 이후 단계별 작은 개발 단위와 완료 기준

아래 5~12단계의 작은 단위를 유지한다. 최신 요청으로 5단계 전투·저장과 계정/결제 정책 모델·협동 시험 구현에 착수했다. 실제 외부 연동은 준비/검증 대기이며 test/ fixture를 운영 권한 우회로 쓰지 않는다. 각 행 전체를 완료로 보지 않고 위 현재 상태 및 실행 증거로 판단한다.
