# 사용자 메뉴 점검 결과 — 2026-10-19

AIRZERO STRIKE 한 앱의 기존 전투·카탈로그·기록·인증 준비 화면을 활용했다. 월간/연간 동일 혜택 구독과 관리자 가격 설정 원칙, 앱 ID·기존 데이터를 유지한다. 스토어 등록·배포·서비스 가입·과금은 실행하지 않았다.

## 저장과 권한 보호

기존 schema 1에 선택 필드 `options`/`lastStage`만 추가했다. 구버전 파일은 기본 음향 설정으로 읽고 클리어/해금/점수/시도 수를 유지한다. 마지막 선택 작전을 재시작 후 유지하고 순차 클리어 시 다음 작전으로 이동한다. 두 사본·체크섬·직렬 쓰기를 유지했다. 초기 읽기 실패/미래 스키마/복구 불가 파일은 쓰기를 금지하고 원본을 보존한다. 안전하게 다시 읽을 수 있는 상태에서만 재시도한다.

설정 저장 실패는 저장 성공으로 표시하지 않는다. 구독 조회의 일시적 실패는 기존에 검증된 유효기간까지만 유지하며 새 권한을 만들지 않는다. 만료/공식 철회 응답은 무료 구성으로 전환한다. 계정/구매 토큰·비밀번호·영수증을 설정 파일에 추가하지 않았다.

## 음향·플랫폼 도구

앱별 pubspec/lockfile에 audioplayers 6.8.1(BlueFire), url_launcher 6.3.3(Flutter), package_info_plus 10.2.2(FlutterCommunity)를 고정했다. pubspec·Android 빌드/manifest와 공식 유지관리자 출처를 먼저 검토했다. 루트 Node 의존성·다른 앱은 변경하지 않았다.

배경음과 사격/피격/스킬/클리어 효과음은 `tool/make_audio.dart`에서 직접 합성한 로컬 WAV다. 앱 자산만 재생하며 오디오 URL·마이크·음원 서비스·외부 분석 SDK는 사용하지 않는다. 전투 일시정지/앱 이탈/메뉴 복귀 시 배경음 중지, 설정 음량 적용, 사격음 빈도 제한을 연결했다. OS 무음/음량/진동 지원은 별도다. 재생 오류는 설정에서 알리고 전투/기록을 막지 않는다.

외부 이동은 확인된 연락처의 정확한 HTTPS URI 또는 공식 스토어 구독 관리 URI만 허용한다. 임의 URL/WebView/인증서 우회는 없다. 외부 앱에 실제 계정이 표시되는 경우 그 내용을 읽거나 수집하지 않는다.

공식 출처: [audioplayers](https://pub.dev/packages/audioplayers), [url_launcher](https://pub.dev/packages/url_launcher), [package_info_plus](https://pub.dev/packages/package_info_plus), [Google 구독 관리 링크](https://developer.android.com/google/play/billing/subscriptions), [Apple 구독 관리 링크](https://developer.apple.com/support/offering-account-deletion-in-your-app/). 링크 연결과 앱의 실제 스토어 결제 구현은 구분한다.

## 검사 결과

- 기존44개+메뉴 회귀12개 전체 호스트 검사56개 통과. 음량 슬라이더·저장 실패 재시도·완료 효과음·구버전 기록 호환을 포함한다.
- 최종 정적 분석 문제 없음. Android 에뮬레이터 통합 검사3개 통과: 파일 기록/순차 해금/빠른 재도전, 무료 이동/실제 보호막/장비·미연결 복원 흐름, 실제 로컬 음원 재생·일시정지·설정 파일 재시작 유지·설치 버전 표시. 배경음의 실제 네이티브 재생 위치 진행도 확인했다. 진동 호출 성공을 실기기 촉감 검증으로 표시하지 않는다.
- 검사에서 드러난 음향 설정 조합 오류와 초기 재생 시간 처리를 수정했다. 음향 위치 UI가 없으므로 매 프레임 네이티브 위치 조회도 제거했다. 가상 플랫폼 검사와 Android 재생 검사를 구분한다.
- 일반 `lib/main.dart` debug APK 빌드·ID metadata 확인·`adb install -r`·Activity 실행 성공. 기존 일반 앱 내부에 만든 빈 검사 표식의 업데이트 전/후 SHA256이 동일했고 그 표식만 제거했다. 실제 사용자 기록/자격증명/구매 자료 본문은 읽지 않았다. 앱 ID·기존 설정 파일·기체 이미지 해시도 유지했다.
- 일반 앱 첫 화면을 에뮬레이터에서 확인했다. 제목/무료·유료 안내/기체/게임 시작/장비/설정/하단 조작 안내가 잘리지 않았다. 환경설정→구독 관리→공식 스토어 관리 버튼을 실제 눌러 Google Play로 전환됨을 확인하고 게임으로 복귀했다. 외부 계정/구독 화면 내용은 읽거나 캡처하지 않았고 실제 구독 목록·해지·결제/복원 검증을 의미하지 않는다. iOS 외부 이동은 미검증이다.
- 문서67개·민감정보 패턴 검사 통과. 루트 배포 CI/Terraform·스토어 작업은 실행하지 않았다. 최종 일반 앱을 에뮬레이터에 실행한 상태로 남겼다.
- 실제 연락처/공개 정책·Auth/서버/스토어 상품·공식 결제/복원·iOS 빌드·실기기 성능/음질/진동은 미검증이다. 버튼 연결 또는 fixture 검사를 외부 기능 완료로 표시하지 않는다.

PowerShell, 앱 폴더에서 실행:

```powershell
flutter --suppress-analytics analyze --no-pub
flutter --suppress-analytics test --no-pub --reporter expanded
flutter --suppress-analytics test integration_test/screen_flow_test.dart -d emulator-5554 --dart-define=AIRZERO_INTEGRATION=true --no-uninstall --no-pub --reporter expanded
flutter --suppress-analytics build apk --debug --no-pub --target-platform android-x64 --target lib/main.dart
```

통합 검사는 별도 `.integration` applicationId와 `--no-uninstall`을 모두 사용한다. Flutter 도구가 이전 APK의 ID를 기억할 수 있어 접미사만으로 일반 앱 데이터 보존을 보장하지 않는다. 네이티브 검사는 임시 경로의 가상 기록만 사용한다. 일반 앱 업데이트 전 반드시 `lib/main.dart`로 다시 빌드하고 APK metadata의 일반 ID를 확인한 후 `adb install -r`로 보존 설치한다.
