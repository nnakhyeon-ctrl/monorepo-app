# 이용약관 로컬 초안

비공개 초안이며 운영자·지원 연락처·출시 국가·정식 약관 확정 전에는 공개/제출하지 않는다.

기본 기체·기본 무장·일반 스테이지·진행/점수 기록은 무료 제공 범위다. 추가 기체·스킬·캐릭터·특수 장비/강화 효과는 월간/연간 구독으로 공식 유효기간 동안 이용한다. 두 구독의 혜택은 같다. 무료 기본 이용은 자동 유료 전환 체험이 아니며 결제수단 등록을 요구하지 않는다. 광고·현금 재화·뽑기는 제공하지 않는다.

가격은 관리자인 사용자만 최종 검토 후 스토어 콘솔에서 설정/변경한다. 앱은 공식 스토어에서 확인한 주기별 총 가격·통화·자동 갱신 조건을 구매 전에 표시한다. 현재 가격·상품은 설정 전이며 실제 결제도 발생하지 않는다. 연간 구독을 월 환산 금액만으로 안내하지 않는다.

자동 갱신 중단은 즉시 만료가 아니다. 공식 잔여 유효기간·적용 유예까지 혜택을 유지하며 만료/철회 시 구독 콘텐츠만 제한한다. 기본 플레이·성장 기록은 유지하고 프리미엄 장착을 기본 구성으로 대체한다. 기록은 구독 만료만으로 삭제하지 않는다.

플레이 코인은 게임 내 성장에만 사용하고 환전·양도·현금 판매하지 않는다. 현재 전체 전투·재화·영구 성장 자동 동기화와 다른 기기 이어하기는 추가 구현/실제 서버 검증 대기다. 계정별 로컬 캐시와 동의한 최초 게스트 기록 보관 기반을 전체 동기화 완료로 표시하지 않는다. 구독 복원은 게임 기록 복구와 별개다.

계정 삭제는 자동 갱신 중단·환불과 다르다. 앱 내 환경설정 → 계정 → 회원 탈퇴에는 최근 본인 확인·삭제 범위·구독 관리·취소/최종 확인·처리 재시도 흐름이 구현돼 있으며 가상 계정으로 검증했다. 실제 서버 삭제와 공개 웹 접수는 미연결이므로 지금 실제 서비스로 제공한다고 안내하지 않는다. 연결 후에도 구독을 이유로 즉시 탈퇴를 막지 않는다. 보관/분쟁/환불 세부 조건·처리 기한·운영자는 실제 국가·운영 조건에 맞춰 공개 전에 확정한다.
