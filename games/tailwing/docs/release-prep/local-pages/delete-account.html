AIRZERO STRIKE 계정 삭제 — 비공개 초안

비공개 초안 — 실제 삭제 접수 서버·공개 URL은 아직 없다. 최종 공개 전 앱 안 삭제와 재설치 없는 외부 요청 경로를 실제 검증한다.

개발자/팀명은 사용자가 지정한 케일이다. 운영 연락처·공개 주소·장애 시 실제 처리 기한은 아직 확정되지 않았으며 임의로 만든 이메일/주소를 사용하지 않는다.

앱 내 요청

환경설정 → 계정 → 회원 탈퇴에서 삭제 범위와 구독 안내를 확인한다. 연결된 이메일 또는 소셜 계정으로 다시 본인 확인한 뒤 최종 탈퇴를 선택한다. 본인 확인/준비만으로 삭제하지 않으며 최종 요청 전에는 취소할 수 있다. 실패/처리 중/완료를 구분하고 완료 확인을 다시 시도한다. 현재 실제 서버는 미배포이며 이 흐름은 demo 계정으로 검증한다.

이 앱의 계정·서버 진행/클리어/최고점수·개인 설정·하위 자료·공급자 매핑·세션과 현재 기기의 해당 계정 캐시/이용권 표시를 정리한다. 삭제 후 복구할 수 없다. 게스트 원본·다른 사용자·다른 앱·공급자 자체 계정은 삭제하지 않는다. 다른 기기의 오프라인 파일을 원격으로 지우지는 못하지만 다음 서버 인증에서 삭제된 계정의 접근/업로드를 거부한다.

재설치 없는 외부 경로 준비

server/firebase/src/deletion-portal.ts에 웹 요청 초안을 두었다. 로컬 npm.cmd run dev:emulator 이후 http://127.0.0.1:5101/demo-airzero-strike/asia-northeast3/api/account-deletion에서 가상 example.test 이메일만 본인 확인·최종 동의·취소·삭제 확인을 시험한다. 비밀번호/토큰/확인값은 URL·분석·웹 저장소로 전달하지 않는다.

이 주소는 사용자용 공개 삭제 URL이 아니다. 운영 웹에서는 입력 폼을 비활성화한다. 실제 이메일/소셜 본인 확인과 웹 전용 App Check/삭제 요청 어댑터는 추가 구현이 필요하다. 현재 서버 App Check 허용 목록은 Android/iOS 앱만 받으므로 공개 설정만 켜서 웹 요청을 허용할 수 없다. 허용 도메인·HTTPS 공개 주소·운영자/지원 경로도 구성하고 재설치 없이 요청을 끝낼 수 있는지 검증한 뒤 공개한다. Apple 실연동도 아직 미완료다. 호스팅 배포나 유료 서비스는 신청하지 않았다.

보관과 처리 기간

정상 연결 시 즉시 정리를 시도하고 장애가 나면 접수와 완료를 구분한다. 준비 요청은 5분, 최종 접수 후 재시도 확인값은 7일 동안 사용할 수 있다. 서버는 확인값 해시와 최소 접근 차단 해시를 보관하며 미완료 작업에는 TTL을 두지 않는다. 실제 운영 worker·7일 기록 정리/TTL·지원 처리 기한은 미적용이므로 운영 보관/처리 완료로 표시하지 않는다. 실제 구매 데이터의 법정 보관 예외·기간은 결제 기능 도입 전에 별도로 확정한다.

탈퇴 시 최근 재인증과 명시적 확인으로 계정·연결 공급자·서버 게임 기록/재화/성장·관련 하위 자료·세션·기기 캐시를 정리한다. 정당한 최소 보관 예외·기간·운영자는 공개 전에 확정한다. 오래된 기기의 기록 재업로드로 삭제 데이터가 재생성되지 않게 한다.

10단계 구매 원장 정리는 로컬 코드/가상 검사로 구현했다. 탈퇴 때 재사용 가능한 암호화 거래 참조·UID·연결 인덱스를 제거하고 임의 재귀속 방지용 가명 표식만 남긴다. 실제 보관 근거/기간·물리 정리·정당한 보유자의 지원 복구 정책은 미확정이며 실제 삭제/결제는 비활성이다. 재화/성장·전체 동기화의 미구현 자료를 삭제 검증했다고 표시하지 않는다. 공급자 연결 매핑 삭제와 카카오/Google/Apple 권한 철회는 다르며, 특히 Apple revoke는 실제 공급자 설정 이후 검증해야 한다.

계정 삭제와 월간/연간 스토어 구독 자동 갱신 중단·환불은 서로 다른 동작이다. 삭제 전에 공식 구독 관리·해지 방법과 결제 영향을 설명하고 즉시 계정 삭제 선택도 제공한다. 구독 해지/만료까지 삭제를 강제로 미루지 않는다. 반대로 구독 만료만으로 게임 기록을 삭제하지 않는다. 복원은 서버 소유 검증을 거치며 삭제한 기록을 구독 복원으로 되살리지 않는다.

구독 관리는 Google Play 또는 Apple에서 확인한다. 앱 계정 삭제만으로 구독이 취소되거나 환불되지 않는다. 이번 단계에서는 구매·구독 취소를 실행하지 않는다.
