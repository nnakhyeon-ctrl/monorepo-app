폰트/게임 음원·기체·배경 등 기존 자산 출처는 [기존 출처](../ASSET-SOURCES.md)·[항공 그래픽](../AVIATION-GRAPHICS-RESULTS.md)을 유지한다. 이번 그래픽 제작이 기존 자산 전체의 라이선스 재감사를 대신하지 않는다. 생성 결과의 서비스 이용 조건/상업 이용 범위는 사용자의 실제 이용 약관과 함께 출시 전 확인하며, 별도 외부 자산 라이선스를 취득했다고 표시하지 않는다.

`local-pages/index.html`은 아이콘 원형/모서리 CSS 마스크 미리보기와 이미지 목록이다. 실제 런처/OS 마스크 통과는 아니다. Android 이미지를 iOS 자료로 가공하지 않는다. 원본·규격 변환본·SHA는 [자료 목록](ASSET-INVENTORY.json)에 보관한다.
