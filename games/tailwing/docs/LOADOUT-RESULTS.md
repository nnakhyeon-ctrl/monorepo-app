# 5단계 한 단위 — 미래형 출격 준비

2026-10-19 사용자 첨부 이미지의 청록 HUD·스킬 카드·미래형 기체를 참고해 ‘기체/능력 선택 → 기기 저장 → 다음 전투 적용’ 한 흐름을 보완했다. 실제 대상은 monorepo 루트 안의 games/tailwing다. 장르는 기존 세로 슈팅을 유지하며 전략 시뮬레이션 전체로 변경한 것이 아니다.

## 구현 범위

| 항목 | 구현 |
|---|---|
| 기체 3종 | 오로라 균형형·벡터 기동형·세이프가드 방어형의 독자적인 새 투명 PNG. 기존 기체/캐릭터 ID·능력·구독 방식 유지 |
| 출격 준비 | 역할·실제 능력·무료/구독·현재 선택·사용 가능 상태, 선택 구성 요약·저장 상태. 스킬은 휴대폰 폭/글자 크기에 따라 2열 또는 1열 |
| 스킬 카드 | 구현된 보호막/오버드라이브/메카 전환/펄스만 새 코드 그래픽으로 표현. 이미지 속 레이저/융단 폭격·스킬 레벨·에너지 비용·재화는 추가하지 않음 |
| 실제 전투 | 첫 화면·선택 카드·전투가 같은 기체별 자산 사용. 하단 고정 버튼으로 바로 출격·로딩·중복 방지·오류 후 재시도, 홈으로 이동은 첫 화면까지 복귀 |
| 선택 저장 | schema 1에 선택적 loadout 필드 추가. 범주별 알려진 ID만 허용, 기존 파일은 무료 기본 선택. 알 수 없는 선택만 기본값 처리하고 점수/해금/설정은 보존 |
| 오류/복구 | 기존 직렬 저장·두 사본·읽기 실패 보호·저장 실패 재시도 재사용. 중복 선택 쓰기 생략. 이미지 준비 중복 요청 합침·부분 디코딩 실패 원복/재시도. 카드 이미지 실패 안내/다시 읽기 |
| 접근 통제 | 저장된 선택은 구매 증명이 아님. 새 실행은 이용권 미확인 시 무료 구성, 기존 검증 인터페이스로 유효 권한을 확인한 경우에만 저장한 유료 선택 복구. 만료/철회 시 무료로 복귀 |

선택 준비 중/기록 보호 모드에서는 변경을 막는다. 유료 권한·만료일·토큰·가격을 로컬 선택 파일에 저장하지 않는다. 로그인·결제 SDK/API·운영 인증·서버 DB를 새로 만들지 않았다. 사용자/객체 권한은 향후 기존 서버 인증 경계에서 처리하며 기체 ID·화면 숨김·시험 이용권을 운영 인증으로 사용하지 않는다.

## 그래픽과 성능

원본 첨부 자료·워터마크를 편집하거나 복사하지 않고 내장 image_gen 도구로 신규 생성했다. 원본 생성 파일과 기존 P-38 이미지/키 아트는 보존했다. 스킬/배경은 기존 Flutter Canvas 방식의 새 벡터 그림이다. 버튼·한글·이용 상태는 실제 위젯이므로 이미지에 굳어 있지 않다.

새 파일: assets/images/aurora_mk2.png, vector_mk2.png, safeguard_mk2.png. 앱 내부에서만 읽으며 네트워크 다운로드/새 권한/SDK/패키지/운영 비용은 추가하지 않았다. 전투 텍스처는 기체당 폭256, 메뉴는512/768로 디코딩하고 장식은 RepaintBoundary로 분리한다. 실제 프레임 시간/발열·장시간 실기기 검증은 별도다.

출처·해시는 [ASSET-SOURCES.md](ASSET-SOURCES.md), 최종 생성 프롬프트와 내장 도구 사용 기록은 [LOADOUT-ASSET-PROMPTS.md](LOADOUT-ASSET-PROMPTS.md)에 있다.

## 검증

- 정적 분석 문제 없음. 전체 호스트 검사63개 통과(기존56+이번7). 기존15탄 무료 공략·메뉴/권한 검사 유지.
- 새 검사: 구버전/잘못된 선택 호환, 파일 재시작 후 선택 유지와 권한 재확인, 연속·중복·실패 저장/재시도, 읽기 실패 쓰기 금지, 3종 투명 PNG 실제 디코딩/부분 실패·재시도, 320×568/글자200% 조작, 직접 출격/중복 방지.
- Android 에뮬레이터 통합 검사4개 통과. 새 검사에서 가상 유효 이용권으로 벡터/펄스/이든/프리즘 선택→네이티브 파일 저장→앱 위젯 재시작→미확인 시 무료 구성→검증 후 선택 복구→기체 이미지 동일성/능력/실제 펄스 적탄 제거·홈 복귀·기존850점 보존을 확인했다. 기존 무료 보호막/해금/재도전/오디오/설정 검사도 통과했다. 가상 이용권을 실제 스토어 구매·복원 검증으로 표시하지 않는다.
- 중단 후 최종 표시 점검에서 2열 카드의 긴 버튼 문구를 ‘능력 보기’·‘선택 잠김’으로 줄였다. 이 문구 변경 후 정적 분석·전체 호스트63개를 다시 통과했고 일반 Android x64 디버그 APK 빌드·기존 ID 확인·install -r 업데이트·실행에 성공했다. 통합4개는 문구 보완 전의 출격 흐름 검증이며 문구 변경 후에는 다시 실행하지 않았다.
- API37 Android 에뮬레이터에서 첫 화면·새 기체 카드·스킬 2열 카드·무료/구독/선택 상태·하단 고정 출격 버튼·뒤로 홈 복귀를 직접 표시 확인했다. 작은 화면/글자 확대는 위 호스트 검사로 확인했으며 실기기 검증과 구분한다. 기존 JBR native-access/SDK XML 경고는 빌드를 막지 않았고 보안 설정을 완화하지 않았다.
- 이전 업데이트 검증에서 직접 만든 빈 시험 파일이 유지되는지 확인한 뒤 그 파일만 제거했다. 실제 사용자 기록·자격증명은 열지 않았다. 기록 보존 근거는 가상850점/구버전 파일 호환 검사와 업데이트 시험이며 모든 실제 사용자 데이터의 보존을 실증한 것은 아니다. 앱 ID·기존 아트·F5 설정·lockfile을 유지했다.
- 루트 문서·민감정보 검사와 git diff --check를 통과했다. 저장소와 앱 ROADMAP에 이 한 단위의 결과를 반영했다.

검사 명령은 PowerShell, 앱 폴더 기준이다.

```powershell
flutter --suppress-analytics analyze --no-pub
flutter --suppress-analytics test --no-pub --reporter expanded
flutter --suppress-analytics test integration_test/screen_flow_test.dart -d emulator-5554 --dart-define=AIRZERO_INTEGRATION=true --no-uninstall --no-pub --reporter expanded
flutter --suppress-analytics build apk --debug --no-pub --target-platform android-x64 --target lib/main.dart
```

네이티브 검사는 별도 .integration ID·임시 파일·가상 이용권만 쓰고 --no-uninstall을 유지한다. 일반 앱 설치 전에는 lib/main.dart로 다시 빌드하고 metadata ID를 확인한 후 install -r로 업데이트한다.

## 다음 단위와 외부 대기

이 단위를 마친 뒤 멈춘다. 적/보스 자산 전체 교체·전장/도시/모선 연출·새 레이저/폭격·성장/재화·전략 시스템은 이번에 구현하지 않았다. 별도 5단계 요청 시 다음 한 단위를 정한다. 실제 로그인/서버 기록/계정 삭제·스토어 구매/복원·가격·공개 문의/정책 URL은 기존 준비 대기다. iOS 네이티브·실기기·두 기기 협동은 미검증이며 협동 메뉴는 계속 숨긴다. 스토어 등록/배포·클라우드 공개·과금·commit/push 없음.
