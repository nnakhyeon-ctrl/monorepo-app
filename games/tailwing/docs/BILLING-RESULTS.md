# 10단계 구독 구매·복원·검증 결과

2026-10-28 11단계 후속: 실제 앱 HTTP 경로 누락·같은 계정의 지연 권한 응답/확인 기한을 보완하고 로컬 회귀 검사를 했다. [11단계 결과](STAGE11-RESULTS.md)를 최신으로 따른다. 아래10단계 통과/미완료 이력·미정 상품 ID/가격·구매 잠금은 유지한다. 실제 스토어/서버·Apple/iOS는 여전히 미검증이다.

## 후속 점검 — 2026-10-28

실제 프로젝트·지침·ROADMAP과 아래 첫 단위 기록을 확인해 이어서 점검했다. **무료 기본 플레이 + 동일 혜택 월간/연간 구독**, 상품 ID/가격 미정과 구매 잠금을 유지한다. 현재 로컬 작업에는 상품을 새로 선택할 필요가 없어 재질문하지 않았다. 실제 콘솔 상태를 다시 읽거나 ID/국가/가격·READY를 설정하지 않았다. 아래 첫 단위의 통과 기록은 이력으로 보존한다.

이번에 가능한 후속 수정·로컬 검증은 마쳤다. 실제 연결과 추가 코드/정책 대기는 아래에 남기고 결과를 저장한 뒤 멈춘다.

### 보완한 부분

- 스토어 가용성 응답을 기다리던 A의 상품 조회/복원 요청은 B/게스트로 전환되면 중단한다. 서버 소유권 검증에 더해 클라이언트도 다음 스토어 동작을 시작하지 않도록 막았다.
- 수동 거래 재시도를 네이티브 콜백과 같은 큐로 직렬화했다. 두 번 재시도하거나 중복 콜백이 도착해도 같은 거래의 완료를 동시에 호출하지 않는다. 계정이 바뀐 대기 재시도도 무효화한다.
- 약관/개인정보/지원 주소를 `PublicContacts.fromEnvironment()`의 공개 빌드 설정으로 연결했다. 기본값은 빈 값이며 허용 주소·상품·계정/서버 확인 전 구매 차단은 유지된다.
- 값·비밀을 출력하지 않는 공개 설정 점검 도구/예시와 검사를 추가했다. 현재 상품 관련 ID7개·공개 주소4개가 미설정인 `PENDING`이다. 로컬 공개 형식 검사나 READY는 실제 연결 증거가 아니다.
- Apple 서버 검증의 공개 CA만 앱 `.gitignore`에서 정확한 파일 경로로 예외 처리했다. 고정 SHA256도 일치한다. 인증서가 새 체크아웃에서 누락되는 문제를 막으며 개인 키/다른 인증서의 제외는 완화하지 않는다.
- 실제 release 빌드에서 이전 통합 검사 registrant의 `integration_test` 참조로 컴파일이 실패한 문제를 발견했다. 현재 Flutter3.47.7은 `--no-pub`일 때 플랫폼 플러그인 재생성도 생략한다. 네이티브 runner의 해당 옵션을 제거하고 기본 `flutter build apk --release --target lib/main.dart`로 공식 재생성을 수행해 빌드에 성공했다. SDK/생성 소스 수동 수정·의존성 업그레이드·서명 설정 변경은 하지 않았다.

## 첫 단위 기록 — 유지

2026-10-28. 첫 단위는 **월간·연간 동일 혜택 구독의 SDK 연결, 구매/복원 상태 처리, 서버 검증과 계정별 이용권**이다. 9단계는 [로컬 검증 완료·실연동 대기](ACCOUNT-MANAGEMENT-RESULTS.md)로 유지한다. 상품 ID는 사용자 답변대로 **미정/미설정**, 가격은 스토어 조회값만 사용한다. 실제 청구·콘솔 등록·배포·운영 자료 삭제를 하지 않았다.

이번 한 단위의 **로컬 구현·최종 검증을 마쳤다**. 상품 미설정/서버 미준비의 기본 거부를 유지하며, 실제 결제·iOS/스토어 연결 완료와 구분한다. 아래 추가 구현/외부 조건을 남긴 상태로 결과를 저장하고 멈춘다.

## 구현한 범위

- 기본 기체·캐릭터·사격·보호막·일반 스테이지·기록의 무료 범위를 유지한다. 추가 기체·스킬·캐릭터·장비는 검증된 구독의 공식 유효기간에만 적용한다. 월간·연간 혜택은 같다. 광고·재화 판매·소비성 상품·새로운 체험/할인을 추가하지 않았다.
- Flutter 공식 배포 `in_app_purchase 3.3.1` 및 Android0.5.5/StoreKit0.4.15 어댑터를 연결했다. 설치된 Android 어댑터는 Play Billing9.1.0, iOS는 StoreKit2를 사용한다. 상품 미설정·미로그인·서버 미준비·가격/공개 약관·개인정보 주소 미확인 시 구매를 시작하지 않는다.
- 구매 화면에서 기간, 스토어 현지 총 청구액/통화, 자동 갱신·해지/환불 안내와 명시적 확인을 표시한다. 상품 ID/가격을 임의로 판매값에 넣지 않는다. 구매 복원·공식 구독 관리·지원/약관/개인정보·탈퇴 경로를 유지한다.
- 취소·실패·PENDING은 새 이용권이 아니다. purchased/restored 콜백은 서버 검증으로 전달하며, 검증 전이나 실패 시 거래 완료/해금을 성공으로 처리하지 않는다. 미완료 거래 재시도와 SDK 재수신을 연결했다.
- 기존 인증 서비스의 검증된 내부 UID/앱 세션과 App Check를 사용한다. 서버가 생성한 스토어별 UUID를 Google obfuscated account ID / Apple appAccountToken으로 전달한다. 이메일을 결제 식별자로 쓰지 않으며 스토어/계정 자동 공유·이전을 하지 않는다.
- Google은 공식 subscriptionsv2 재조회로 앱·상품/base plan·testPurchase 환경·계정 연결·상태/만료를 확인한다. Apple은 공식 App Store Server Library의 API와 Apple CA를 고정한 JWS 검증으로 앱/환경·구독 그룹·상품 유형·원거래·계정 토큰·갱신/철회를 확인한다. 클라이언트의 success/paid 플래그는 검증 자료가 아니다.
- Firestore의 앱/환경 범위 원장과 거래군 임대로 중복/동시 검증을 제어한다. 거래 참조는 서버 전용 키의 AES-256-GCM으로 암호화하고 앱/환경/원장에 묶는다. 기기 파일에 영수증이나 영구 premium 플래그를 보관하지 않는다.
- Google 검증 제공 기록을 먼저 저장한 뒤 acknowledge한다. 실패하면 미확인/재시도 상태이며 새 구매로 덮어쓰지 않는다. 구독은 consume하지 않는다. Apple의 거래 완료는 검증/처리 뒤 SDK completePurchase로 수행하고 미완료 큐를 재처리한다.
- Google RTDN/OIDC와 Apple V2/JWS 경로, 별도 OIDC 유지보수 경로를 추가했다. 알림의 활성/만료 주장을 적용하지 않고 공식 현재 상태를 재조회한다. 중복/역순에도 지급량을 누적하지 않는다. 앱 종료 직후 첫 거래는 사전 인증된 구매 연결값이 있는 계정에만 귀속할 수 있다.
- 자동 갱신 중단은 남은 기간을 유지하고 공식 grace/hold/pause/expired/revoked를 구분한다. 만료/환불 때문에 게임 기록을 삭제하지 않는다. 기존 구독이 있으면 두 번째 구매/미완료 상태의 재구매를 차단한다. **앱 내 월↔연 교체 구매는 이번 단위에서 제공하지 않는다.**
- 계정 전환·탈퇴 시 이전 응답/캐시를 분리한다. 탈퇴는 구매 연결 매핑·UID·재사용 가능한 암호화 참조를 제거하고 자동 이전 방지를 위한 가명 소유권 표식만 남긴다. 실제 보관 근거/기간/정리 정책은 출시 전 확정해야 하며 준비 플래그를 켜지 않았다.

| POST `/v1/billing/intent` | 기간 확인·기존 구독 검사·서버 구매 연결값 발급. 가격/UID를 본문에서 받지 않음 |
| POST `/v1/billing/verify` | 상품 ID/참조를 공식 재검증·소유권 고정·멱등 반영 |
| POST `/v1/billing/notifications/play` | 허용 OIDC 주체/정확한 audience 검증 후 공식 재조회 |
| POST `/v1/billing/notifications/apple` | Apple 서명 검증 후 공식 현재 구독 재조회 |
| POST `/v1/billing/maintenance` | 별도 허용된 worker OIDC만 허용. 실패 거래가 다른 거래를 막지 않도록 분리 재시도 |

인증·활성 계정/세션·앱·환경을 확인하고 준비된 결제 API는 계정당 분당30회로 제한한다. 같은 이메일·클라이언트 UID·임의 구매 플래그로 접근하지 않는다. 운영 fake proof/StoreKit 로컬 결과를 받는 토글은 없다. 가상 verifier/스토어 구현은 test 파일에만 있다.

## 오프라인·이용권 확인 기한

영구 오프라인 해금이나 기기 영수증 자체 검증은 이번에 선택하지 않았다. 공식 만료 시각과 별개로 **최대2분의 서버 확인 기한**만 메모리에서 사용한다. 타이머로 기기 시계 변경에도 기한을 연장하지 않으며, 기한 경과/재검증 실패/계정 변경 시 미확인으로 돌아간다. 앱 재시작 시 보호 저장소의 premium 플래그로 복구하지 않는다. 무료 플레이와 기록은 계속 유지한다. 이 짧은 확인 기한 동안 실제 철회 반영이 지연될 수 있으며 루팅 기기의 로컬 게임 변조까지 막는다는 주장은 아니다.

가상 검사는 본인 A/B·미인증/만료·소유자/다른 스토어 혼합·대기 신규 지급 거부·검증/ack 실패 재시도·중복 완료·알림 역순·자동 갱신 중단/유예·보류/만료/철회·앱 종료 직후 첫 거래·탈퇴 후 재귀속 거부를 대상으로 한다. 실제 Google/Apple 응답의 성공을 가상 검사로 대체하지 않는다.

검증 중 발견한 문제는 복원 화면이 기존 인터페이스를 우회한 부분, 교체된 버튼을 참조하던 검사, 한 거래의 실패가 worker 전체를 막던 부분이었다. 기존 복원 인터페이스를 재사용하고 실제 구매 버튼의 차단 상태와 동의 조작을 검사하며 worker 실패를 개별 재시도하도록 수정했다. Android 인증 검사는 기존 소셜 grant 우회 거부·이메일 확인/초기 게스트 보관/비밀번호 재설정·가상 A/B 기록 복구와 A만의 탈퇴를 재확인했다. 응답 유실/정리 실패 재시도는 Flutter/서버 통합 검사에서 통과했으며 실제 사용자 계정을 시험 삭제하지 않았다.

공식 Play 응답의 `autoRenewingPlan.installmentDetails`·`prepaidPlan`도 서버에서 명시적으로 거부하도록 보완했다. 미선택 할부/선불 거래를 클라이언트 필터에만 맡기지 않으며 해당 오류 입력을 포함한 서버20개 검사를 다시 통과했다. [공식 구독 응답 필드](https://developers.google.com/android-publisher/api-ref/rest/v3/purchases.subscriptionsv2#AutoRenewingPlan).

Android는 `Medium_Phone_API_37.0` 가상 기기의 별도 `com.example.raikeopeu2026.dev.integration` 앱·`AIRZERO_INTEGRATION=true`·`--no-uninstall`로 검사했다. APK의 package ID도 대조했다. 일반 앱의 저장소 초기화/앱 삭제를 하지 않았다. 가상 기기는 앞서 확인한 `-gpu host -feature -Vulkan` 옵션을 유지했으며 AVD 기본 설정은 변경하지 않았다. 합성 전투128프레임의 decoded 7,632,384 bytes·raster p95 23.91ms·build p95 49.50ms는 디버그 가상 기기 수치로 실기기 프레임/발열 보장이 아니다. 로컬 Node24.21.0·JBR25.0.3을 사용했으며 운영 대상 Node22는 미검증이다.

문서7개의 로컬 링크78개가 존재하며, 명시한 소스 폴더의 Dart/TypeScript/검사 도구51개에서 개인 키 본문/서비스 계정 키 패턴을 발견하지 않았다. 이 제한된 검사는 전체 비밀/로그/Git 추적 검사를 대신하지 않는다. Git 소유자 불일치 보호를 완화하지 않아 Git 기반 전체 변경/추적 검사는 여전히 미검증이다.

운영 의존성 body-parser2.3.0의 알려진 서비스 거부 항목을 공식 호환 범위의2.4.0으로 갱신했다. `npm audit --omit=dev`의 알려진 운영 취약점은 **0건**이다. 전체 개발 도구/모든 보안 위험이 없다는 뜻은 아니다. Apple 공식 라이브러리의 jsrsasign 유지보수 중단 안내와 기존 FlutterFire KGP·JDK/SDK 경고는 강제 override로 숨기지 않는다.

## 실제 연결·추가 구현 대기

1. **9단계 선행:** 실제 인증 서버·Google/Kakao 로그인·App Check/IAM/보안 규칙·Apple 로그인·외부 삭제 요청·iOS/실기기 검증은 여전히 미완료다. 이 조건 없이 실제 결제 통합 완료로 넘어가지 않는다.
2. **상품/가격:** 사용자 확인으로 미정이다. Play 동일 구독의 월/연 base plan, Apple 동일 그룹/등급의 월/연 상품과 판매 국가·현지 가격·약관/개인정보/지원 URL은 설정 대기다.
3. **서버:** 검증용 서비스 계정/공식 API 권한·서버 secret·실제 RTDN/V2·worker 실행/감시·요청 제한 TTL·구매 보관/정리 정책이 미적용이다. READY는 자동 점검기가 아니며 현재 비활성이다. Firebase Spark를 과금 전환하거나 배포하지 않는다.
4. **스토어/장비:** Google 라이선스 테스터·테스트 결제수단과 Apple Sandbox·Mac/Xcode/iPhone이 필요하다. Apple 계정 로그인만 있고 유료 Developer 멤버십은 없다. 가입/결제/콘솔 등록/테스트 배포를 대신 수행하지 않는다.
5. **후속 같은 단계:** 실제 미완료 거래 큐/ack 기한·운영 알림 누락/순서/부하와 Apple 실제 서명/OCSP를 검증해야 한다. 월↔연 공식 교체·탈퇴 후 정당한 보유자의 지원 복구 절차·제공 불가 Google 거래의 빠른 취소/환불 자동화는 추가 구현/정책 검증이 필요하다. 소유자 불일치 요청으로 타인의 거래를 환불시키지 않는다. 현재 환불/해지 쓰기 API를 실행하는 기능은 없다.
6. **국가/정책:** 디지털 게임 혜택은 기본 네이티브 IAP만 구현했다. 한국 등 국가별 대체 결제/외부 링크 예외나 별도 프로그램은 자동 적용하지 않는다. 판매 국가/스토어 계약이 확정되면 최신 정책을 다시 확인한다. 심사 통과를 보장하지 않는다.

세부 직접 준비는 [BILLING-SETUP.md](BILLING-SETUP.md). 이번 한 단위의 로컬 결과를 저장한 뒤 멈추며 11단계로 자동 이동하지 않는다. 앱 ID·기존 데이터·다른 앱을 변경하지 않았고 commit/push를 하지 않았다.
