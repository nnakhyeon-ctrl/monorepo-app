# 참고 이미지에서 개선한 화면과 아트

2026-10-18 추가 참고에는 어두운 세로 전장, 청록색 아군탄/따뜻한 적탄, 넓은 함선형 보스·레이저 예고, 기체/보조기/캐릭터를 배열한 격납고가 보인다. 정지 이미지로 실제 판정·과금·게임 로직을 확인한 것은 아니다. 기존 초창기 이미지의 대형 항공기·숲/활주로 방향도 유지하며 구조와 가독성만 참고한다.

## 적용한 기본 화면

| 참고 요소 | 이 앱의 새 구성 | 현재 상태 |
|---|---|---|
| 조밀한 전장과 여러 자원 HUD | 단순한 정보 영역, 아군 긴 청록 탄환/적 원형 따뜻한 탄환, 어두운 낮은 대비 배경 | BattleConceptPainter의 정적 전투 구성안 |
| 큰 보스·부품·레이저 | 독자적인 각진 공중 요새, 분리 포대·부채꼴 예고·점선 위험 구역 | 시각 미리보기, 체력/충돌/실제 발사는 5단계 |
| 다수의 기체 선택 | 오로라-01 기본 무료, 벡터-02/세이프가드 추가 구성, 새 벡터 실루엣과 절제한 색 | 격납고 기체 분류·상세 보기, 지급/장착 없음 |
| 조종사·드론 슬롯 | 기체·스킬·캐릭터·아이템 분류, 이름/기능 설명과 구독 전용 잠금을 카드로 구분 | 구성안. 원본 인물 초상·국기·슬롯 장식/수치/로고 복제 없음 |
| 성장·강화 정보 | 무료 진행/점수 기록과 구독 전용 선택형 강화 효과 구분, 기록/재화 가짜 숫자 표시 없음 | 능력 수치·가격·확률·할인 미정 |

전투/기체 그림은 Flutter CustomPainter에서 직접 만든 코드 기반 벡터다. 참고 스크린샷·ROM·원본 스프라이트·음원·게임명·인물 사진을 앱에 넣지 않는다. 기존 새 격납고 키 아트와 배색은 보존한다. 자산 경로/출처는 [ASSET-SOURCES.md](ASSET-SOURCES.md)에 기록한다. 새 기체/캐릭터 명칭도 출시 전 검토할 구성안이다.

## 게임 구현에서 지킬 기준 — 5단계

- 아군/적 탄환을 색뿐 아니라 형태·외곽선·이동으로 구분하고 공격을 예고한 뒤 발사한다. 필요한 접근성·명확한 판정은 무료 공통이다.
- 작은 중심 판정, 손가락 아래 조작 공간, 안전 영역·작은 휴대폰·글자 확대를 고려한다. 무료 기본 기체로 일반 콘텐츠가 진행 가능하도록 검증한다.
- 부위 파괴 시 해당 포대의 충돌/발사를 실제로 종료하고 페이즈·약점·회피 통로를 같은 시드로 검증한다.
- 장식 입자·배경·회전 효과를 제한하고 기체/탄환 풀링·상한·해제를 검증한다. 60fps는 측정 목표이며 지금 달성했다고 표시하지 않는다.
- 현재 미리보기는 애니메이션·게임 루프·입력/사격·충돌·아이템/구독 지급이 없다. 실제 전투처럼 오해하지 않도록 구성안/준비 상태를 표시한다.
