## Git/GitHub 저장 상태

- 로컬 `main`: 커밋 없음, 브랜치 이력/reflog 없음. 앱 소스 포함 파일은 미추적 상태다. 따라서 `git diff`가 비어 있어도 저장된 커밋과 같다는 의미가 아니다.
- origin은 사용자 저장소 `https://github.com/nnakhyeon-ctrl/monorepo-app.git`다. GitHub 연결 도구 조회에서 크기 0, 기본 이름 main, 브랜치 목록 없음. `git ls-remote --heads --tags origin`도 종료 코드 0/출력 없음으로 브랜치·태그가 없는 상태를 확인했다.
- 복구 가능한 원격 커밋은 확인되지 않았다. 현재 로컬 파일·결과 문서·가상 검사 자료가 재개 기준이다. commit/push/fetch/checkout/reset/원격 생성은 하지 않았다. GitHub에 백업됐다고 표시하지 않는다.

## 현재 PC에서 복구·검증한 것

이전 `.dart_tool` 설정은 `C:\Users\user` 아래의 Flutter/패키지를 가리켜 검사 시작에 실패했다. 누락 Flutter 공식 자산을 준비하고, 기존 pubspec/lockfile을 확인한 뒤 `pub get --enforce-lockfile`로 고정 버전을 복원했다. 패키지 버전 업그레이드는 하지 않았다. 오프라인 시도는 캐시 부족으로 실패했고, 네트워크 복원 후 성공했다.

- 디자인/홈/12종/수명주기/선택/전투/기본 화면/환경설정 **8개 파일 96개 검사 통과**, 종료 코드 0, 약 28초. 이전 결과의 95개는 당시 이력으로 보존한다.
- `flutter analyze --no-pub`: **문제 없음**, 종료 코드 0, 12.6초. 처음 sandbox에서는 분석기 상태 폴더 생성이 거부되어 승인 경로로 재실행했다.
- 280/320/396 폭, 글자 1배/2배, 출격 위치, 선택 전환/구매 잠금, 갑판 전개/내구 소진/시간 종료/초기화가 위 가상 검사에 포함된다.

## 실제 실행과 남은 중단 지점

PowerShell에서 저장소 루트를 열고 다음 명령으로 같은 검사를 실행할 수 있다.

```powershell
Set-Location -LiteralPath 'C:\Users\nnakh\OneDrive\Desktop\App\monorepo\games\tailwing'
& ..\..\flutter\bin\flutter.bat --suppress-analytics analyze --no-pub
& ..\..\flutter\bin\flutter.bat --suppress-analytics test --no-pub test/tailwing_design_test.dart test/animal_home_test.dart test/animal_roster_test.dart test/animal_lifecycle_test.dart test/loadout_preparation_test.dart test/battle_flow_test.dart test/basic_screens_test.dart test/menu_settings_test.dart
```

현재 PC 기본 Android SDK 위치 `C:\Users\nnakh\AppData\Local\Android\Sdk\platform-tools\adb.exe`는 없다. Android Studio JBR은 존재한다. 다른 위치의 SDK 설치 여부는 미확인이다. **현재 PC의 실제 앱 실행/새 Android 빌드/캡처/성능 검사는 미검증**이다. 기존 APK 파일의 존재만 확인했으며 오늘 다시 빌드/설치했다고 표시하지 않는다.

실행을 이어갈 때 Android Studio의 SDK Manager에서 실제 SDK 위치와 가상 기기를 먼저 확인한다. SDK 준비 후 앱 폴더에서 아래 명령을 실행하거나 VS Code F5를 사용한다. 기기 ID는 본인 PC에서 선택하고 기존 앱 제거/데이터 초기화는 하지 않는다.

```powershell
& ..\..\flutter\bin\flutter.bat devices
& ..\..\flutter\bin\flutter.bat run --debug --dart-define=AIRZERO_INTEGRATION=true -t lib/main.dart
```

위 실행은 기존 일반 앱과 구분되는 `.integration` debug 앱을 사용한다. 로컬 빌드/검사 도구 일부에는 아직 이전 PC의 Flutter/Android SDK 절대 경로가 남아 있다. 특히 `tool/build_tailwing_apk.mjs`를 현재 PC에서 바로 실행 가능하다고 보장하지 않는다. 실제 SDK 위치 확인 후 필요한 도구만 수정해야 한다. 자산 생성 이력의 과거 원본 경로를 현재 경로로 일괄 치환하지 않는다.
