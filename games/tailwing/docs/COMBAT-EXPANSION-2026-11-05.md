## 변경한 기능

- `PlayerAircraft`: 실제 위치(x/y), 이동 배율, 이동 속도 벡터, HP, `AircraftHitbox`를 분리했다. 기울임은 화면 연출이고 기존 원형 피격 반경 10·이동 경계는 같다. 기존 1024px 토끼/거북이 원본과 256px 전투 디코딩을 유지했다.
- 기체 엔진에 고정 16개 수식 기반 입자를 추가했다. 입자 객체를 매 프레임 생성하지 않으며 동작 줄이기에서는 기울임·추가 입자를 생략한다. 플레이어의 흰 피격점과 위험 탄환은 효과보다 위에 그린다.
- `ProjectilePool`: 일반·동물 기술·유도 미사일의 탄환 객체를 재사용한다. 반환된 객체 보관은 풀당 최대 256개이며 살아 있는 탄을 개수 때문에 삭제하지 않는다. 위치/속도/피해/피아/수집/정밀/유도 여부와 유도 시간이 재설정된다. 곰의 수집 탄은 보관 종료까지 반환하지 않고 협동 탄은 원래 소유 풀로 반환한다.
- 상단 네온 HUD에 장갑 아이콘·실제 점수/격추·작전 진행과 보스 Phase/남은 부위 수를 표시했다. 하단은 기본 보호막과 장착 고급 기술의 2개 슬롯이며, 기본 구성에서는 보호막과 자동 사격을 표시한다. 자동 사격을 가짜 두 번째 능동 스킬로 표시하지 않는다. 시간/쿨타임 원형 오버레이와 준비/차지/작동 문구가 연결된다.
- 기본 보호막은 터치 또는 Z, 장착 기술은 SPACE로 사용한다. 기존 드래그/방향키 이동·자동 사격과 기본 2초/10초, 거북이 기본 보호막 보정·전방 갑판의 3초/13초·5발·폭70·거리20–60을 유지했다. 구독 고급 기술을 장착해도 무료 보호막을 독립적으로 사용할 수 있다.
- 좁은 화면/큰 글씨에서는 슬롯을 세로로 배치한다. 일시정지/결과는 전체 화면 패널로 옮겨 작은 전투 영역 밖으로 다음 작전 버튼이 잘리는 오류를 수정했다. 튜토리얼의 이동 안내는 이동 터치를 가로채지 않는다.

## 구독·기록 보호

- `AccountStatus.isSubscribed`, `subscriptionType(none/monthly/yearly)`, `expirationDate`는 검증된 `SubscriptionAccess`의 읽기 전용 투영이다. `PermissionManager`가 현재 시각과 만료를 확인한다. 로컬의 임의 `isSubscribed: true`는 권한이 아니다.
