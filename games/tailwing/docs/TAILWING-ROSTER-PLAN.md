# 테일윙 · TAILWING 12종 리뉴얼 설계

후속 요청 반영: 독수리와 피카츄 복제 없이 독자 설계한 전기땃쥐를 추가해12종이다. 귀여운 미래형·디지털 계기/발광 패널·둥근 기체가 현재 최종 방향이며 아래 초기 프로펠러/고전 정비 콘셉트는 제작 이력이다. 소형 우주선/부유 자동차/비행기 등으로 탈것을 구분한다. 탑뷰 전투는 기수와 조종사 모두 위를 향하고 후두부/귀가 보이며, 홈/선택은 별도 얼굴 초상으로 자연스럽게 보여준다. 이전 피드백의 역방향 좌석/구식 기체 시안은 적용하지 않는다. 특정 연도 유행/반응/상업 성과가 검증됐다는 주장은 하지 않는다.

2026-10-29 사용자 범위 확장. 기존 프로젝트/앱·상품·서명·저장 ID를 유지하고 표시명만 변경한다. 무료3종(토끼/여우/거북이), 기본 사격/보호막; 검증된 월·연 구독은 모든 캐릭터와 고유 기술/기존 추가 콘텐츠. 가격·상품 ID/구매 잠금·실연동 대기는 유지한다. 신규 개별 판매/중복 과금 없음.

## 순서와 경계

대표 토끼의 자산→홈/선택/전투→경로/종료/피격 검증 후 2~10번에 공통 구조를 확장한다. 효과 시간·재사용/피해/거리/개수/대상은 `animal_roster.dart`의 설정값으로 분리한다. 기존 pilot/rion/eden ID는 이름/외형 리뉴얼이며 이전 선택 기록을 버리지 않는다. 무료3종 변경은 사용자의 추가 답변으로 승인됐고 기존 공격/장갑 특성은 유지한다. 고유 기술은 별도 `signature` 구독 스킬이며 무료3종도 기본 사격·보호막으로 진행할 수 있다.

일반 앱의 계정별 선택/출격은 기존 LoadoutController/서버 확인 권한을 재사용한다. 개발 연구소는 debug 전용·무기록·무구매·격리 전투이며 release에서 강제 차단한다. 기체 항목3개/소유권 ID는 삭제하지 않고, 캐릭터별 기본 기체 외형을 기본 aurora 선택 시 연결한다. 추가 기체 선택은 기존 기체 능력을 유지한다.

현재 엔진에 필요한 변경: 이동 경로 제한 큐·개별 적 피해 예산, 일반/특수 적탄 표식, 방향성 차단, 명중 콜백/연결 예산, 고정 대상 예고/탄종, 설치물 TTL/개수, 둔화/면역 타이머, 새로운 조준 결정 시 잔상 선택. 기존 탄환 속도/이미 발사된 조준은 변경하지 않는다. 공통 시뮬레이션을 쓰는 비공개 협동도 상태 표현 영향을 받으므로 별도 회귀 검사하며 실제 두 기기 협동은 여전히 미검증이다.

초상/전투 자산·연동·검증은 [결과](TAILWING-ROSTER-RESULTS.md)에 종별로 기록한다. 미완성 자산/기술은 완료로 표시하지 않는다. 리뉴얼 이후11단계 변경 영향 재검증과12단계 새 아이콘·실제 캡처/소개/정책·서명 파일 재생성이 필요하며 기존 AIRZERO 자료는 역사적 스냅샷이다. 공개/스토어 등록은 하지 않는다.
