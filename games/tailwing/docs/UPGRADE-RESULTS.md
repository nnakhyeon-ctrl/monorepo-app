- 구독: 월간/연간 선택은 기본 미선택이며 주기별 총 청구액/갱신 안내를 표시한다. 현재 관리자 가격 설정/스토어 연결 대기이며 선택만으로 결제/유료 권한이 생기지 않는다.

## 이름 변경 전 메인 화면 재구성 이력

2026-10-18 사용자가 하단 버튼 배열·이름·메인 이미지 전체 개선을 요청했다. ‘스톰윙(STORMWING)’을 새로운 제안 작업명으로 적용했다. 최종 이름 선택·상표/스토어 가용성 확인은 별도이며 기존 라이커프 시리즈 2026과 동일한 앱이다. 폴더·Dart package·applicationId/Bundle ID·저장 경계는 유지한다.

- 메인 이미지: 구름 사이로 상승하는 독자적인 은빛 전투기 장면을 내장 image_gen으로 새로 생성했다. 전체 날개가 보이도록 원본 비율을 유지하고 남색 배경에 가장자리를 부드럽게 연결한다. 이전 격납고 PNG는 보존했다. 파일·해시·최종 프롬프트는 [ASSET-SOURCES.md](ASSET-SOURCES.md)에 있다.
- 시각 순서: 브랜드/도움말 → 게임 이름과 한 줄 소개 → 새 비행 장면 → 큰 ‘게임 시작’ → 무료/구독 범위 한 번 안내 → 간결한 세 메뉴 → 하단 문구로 정리했다. 과한 광원 효과·자동 애니메이션·가상 전투 수치·추가 기능은 넣지 않았다.
- 하단 메뉴: ‘전투기·장비 / 구독 관리 / 환경설정’을 같은 크기의 가로 버튼으로 맞췄다. 이전의 크기가 다른 카드·긴 보조 설명·중복 설정 버튼은 줄였다. 글자를 키우거나 화면이 좁으면 세로 목록으로 바뀌고 스크롤로 모두 접근한다. 화면 읽기에는 메뉴 목적을 추가 설명한다.
- 하단 문구: ‘오늘의 한계를 넘어, 다시 출격.’ 지원 및 안내는 상단의 도움말 버튼으로 연결한다. 기록 이어하기는 환경설정 안에 유지한다.
- 이름 적용: Flutter 앱 제목, Android/iOS 표시명, F5 실행 이름과 현재 안내 문서를 맞췄다. 개발 package와 파일 경로는 변경하지 않았으며, iOS 네이티브 표시는 Mac에서 확인해야 한다.
- 범위: 실제 전투·장착 효과·서버 동기화·구독 검증은 이후 단계다. 게임 시작은 기존 구성안 안내로 연결되며 결제·회원가입 성공을 흉내 내지 않는다.

정적 분석과 기존 화면 검사 15개는 새 레이아웃에서도 통과했다. Android 통합 이동 1개 흐름과 최종 일반 앱 실행도 통과했다. 가상 기기의 최종 화면에서 새 이름·전체 기체 이미지·동일 규격 가로 메뉴·하단 문구가 함께 보이며 글자/버튼이 잘리지 않는 것을 확인했다.

## 메뉴 명칭·가독성 보완 이력

2026-10-18 첨부된 첫 화면을 기준으로 메뉴의 목적을 바로 알 수 있게 다듬었다. ‘격납고’ 메뉴와 연결 화면은 ‘전투기·장비’, ‘구독·복원’ 메뉴와 이용권 화면은 ‘구독 관리’로 통일했다. 배경의 격납고 분위기와 기존 게임 아트는 유지한다.

- 전투기·장비: ‘스킬·캐릭터 / 아이템 선택’ 설명으로 구성 범위를 알린다.
- 구독 관리: ‘혜택 확인과 / 이전 구매 복원’ 설명을 표시한다. 하위 ‘구독 구매 복원’ 화면은 이전에 결제한 구독의 남은 혜택을 확인하는 절차이며 새 결제·게임 기록 복구와 다르다는 설명을 제공한다.
- 기록 이어하기: 최신 사용자 지시에 따라 첫 화면의 별도 카드를 제거했다. 기본 진입은 ‘환경설정 → 게임 기록과 구독 → 기록 이어하기’다. 첫 화면의 환경설정은 간결한 가로 메뉴로 배치했다. 환경설정에는 로그인·계정 관리·기록·화면 효과·도움말을 모으고, 구독 구매 복원/지원의 관련 안내 링크는 유지한다.
- 메뉴 카드: 같은 행의 높이·안쪽 여백을 맞추고 이동 화살표와 옅은 테두리를 추가했다. 설명은 짧은 두 줄로 나누고, 좁은 화면·큰 글씨에서는 한 열로 바꾼다. 고정 높이·말줄임으로 내용을 숨기지 않는다.
- 기본 무료·구독 전용 범위와 관리자 가격 설정 대기 상태를 유지한다. 실제 장착·결제·인증 기능은 추가하지 않는다.
