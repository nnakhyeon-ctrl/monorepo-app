## 버전·빌드·소스 상태

현재 버전은 `0.1.0+1`, Android/iOS ID는 기존 `com.example.raikeopeu2026.dev`를 유지했다. 출시 대상 ID/기존 스토어 최고 빌드 번호는 소유자 확인 전이며 임의 변경하지 않았다. 기준 소스는 Git `f8f8b3a`이고 이번 변경은 문서/검증·자료 도구/벡터 후보/CI 범위다. 게임·인증·결제·native Gradle 소스는 수정하지 않았다. 자료 해시는 현재 작업 파일의 원시 바이트 기준이며 Git의 LF 정규화 트리 ID와 구분한다.

Android SDK/실제 release signing 연결은 미준비다. 점검용 서명 경로 환경 변수도 미설정이며 실제 키/암호/프로파일을 읽거나 생성하지 않았다. 서명 AAB는 **미생성**, 현재 AAB 서명/설치·로그인 callback/16KB·실기기 성능은 **미검증**이다. 기존 debug/미서명 APK가 있더라도 [플랫폼 보고](release-prep-2026-11-04/READINESS.json)에 현재 서명/소스 일치/실행 미확인으로 기록했다. 제출용으로 승격하지 않았다.

iOS는 Windows에서 Mac/Xcode/Team·프로비저닝 미준비로 Archive/IPA를 만들지 않았다. 클라우드 빌드는 선택/사용하지 않았다. 직접 준비 조건과 실제 산출 폴더·SHA/서명 검사 순서는 빌드 문서에 남겼다. 공개/결제 설정이 없어도 성공한 것처럼 바꾸지 않았다.
