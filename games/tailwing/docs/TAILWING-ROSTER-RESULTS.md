### 메모리·로딩·성능

최종 가상 실행에서 scene+12기체 디코드 **7,084,032B(약6.76MiB)**, 개별 기체 로딩29~128ms,740프레임·build p95 **109.173ms**/raster p95 **55.268ms**를 기록했다. 동시 호스트 검사/빌드가 있는 debug 에뮬레이터 수치이며 첫 실행보다 느렸다. **60fps/실기기 발열·입력 반응 통과가 아니다.** 기체는256폭 지연 디코드, 초상은 제한된 cacheWidth, 효과48/경로8/연결12/설치2/수집6 상한을 적용한다. 실기기 profile/release 성능은 대기다.

### 실행·권한·남은 일

개발 APK는 [BUILDS.json](tailwing/BUILDS.json)의 `preview` 경로를 따른다. 기존 일반 앱과 분리된 `.integration` ID·debug 전용이며 제출/배포용이 아니다. 앱 내 ‘개발 연구소’에서는12종을 무기록/무구매로 시험한다. 일반 게임은 검증된 구독 상태만 사용하고, 연구소는 release에서 진입/권한 경로를 열지 않는다. 공식 스토어/서버 미연결을 임시 해금으로 우회하지 않았다.

이 개발 APK 설치는 별도 가상 앱에만 `install -r` 성공, 최초 cold launch `Status ok`/12,160ms였다. 이후 PID가 없던 이유는 확정하지 못했다. 재실행 한 번은 대기 초과였고 그 뒤 두 차례 프로세스 생존·warm launch `Status ok`를 확인한 후 소유한 시험 VM을 종료했다. 이 결과를 안정성/성능 최종 통과로 표시하지 않는다. 개발 APK의 소스 지문은 마지막 제어문 괄호 2곳의 lint 수정 전 빌드 시점이며, 새 미서명 release는 그 수정과 최종 분석을 포함한 현재 소스다. 화면/기술 동작 변경은 없고 각 파일의 정확한 SHA/소스 범위를 빌드 기록에 구분한다. 기존 일반 앱과 사용자 데이터를 설치/제거 대상으로 삼지 않았다.

새 고정 release 검사 사본 SHA-256: `42431bb323bca13392090c2c5bf2db31dcc598511a8006f3c439ade759b9fb7f`. 현재 Git HEAD/추적 이력은 없고 앱은 untracked 상태이므로 이 해시/제한 소스 지문을 commit 증거로 해석하지 않는다. 자동 commit/push 없이 파일로 저장했다.

재현: 앱 폴더에서 `node tool/build_tailwing_apk.mjs preview`, `node tool/capture_tailwing_android.mjs`(소유한 전용 가상 기기·가상 데이터만), 카드만 재검증 시 `--cards-only`, `node tool/prepare_tailwing_review.mjs`. 실제 사용자 기기에 시험용 APK를 덮거나 기존 앱을 제거하지 않는다.
