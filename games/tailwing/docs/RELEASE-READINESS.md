## 협동 서버 비용 가정

현재 로컬 PC 시험은 클라우드 리소스를 만들지 않았다. 운영 제안은 기존 Firebase 인증/기록 API와 별도로 권한 있는 실시간 WSS 프로세스를 두는 것이다. Firestore에 매 탄환/프레임을 쓰지 않는다. Cloud Run을 선택한다면 열린 WebSocket 동안 인스턴스가 활성 상태로 과금되고, 요청 제한 시간·재연결·여러 인스턴스의 상태 공유를 설계해야 한다. 단순 세션 affinity만으로 방 일관성을 보장하지 않는다. [공식 WebSocket 안내](https://docs.cloud.google.com/run/docs/triggering/websockets).

2026-10-19 공식 요금표의 Iowa 기본 인스턴스 기반 단가를 예산 계산의 예로만 사용한다: vCPU초 $0.000018, GiB초 $0.000002. 한국 리전 견적·세금·환율·무료 할당·할인·트래픽·DB·로그·빌드/이미지 저장비는 아래에서 제외했다. [Cloud Run 공식 요금표](https://cloud.google.com/run/pricing).

| 가정 | CPU+메모리 계산 | 월 예시 |
|---|---|---|
| 1vCPU+0.5GiB 인스턴스 1개, 하루 6시간×30일 활성 | 648,000초 × ($0.000018 + 0.5×$0.000002) | 약 $12.31 + 기타 비용 |
| 같은 인스턴스 1개 24시간×30일 활성 | 2,592,000초 × 같은 단가 | 약 $49.25 + 기타 비용 |
| 같은 인스턴스 2개 상시 활성 | 위의 2배 | 약 $98.50 + 기타 비용 |

용량/인스턴스 수는 실제 방 수·틱 CPU·메모리·동시 연결 부하 검사 후 결정한다. 로컬 서버의 방16/접속32 제한은 운영 처리량 보장이 아니다. 2~6KiB 스냅샷을 20Hz로 두 명에게 5분 보내는 가정은 방당 약 23~70MiB, 월1,000방 약23~69GiB의 전송량이다. 실제 JSON 크기·압축·지역별 egress와 왕복 지연을 측정해야 한다. 대기실 연결도 비용을 만들 수 있어 TTL·인스턴스 상한·예산 알림·트래픽 제한을 함께 정한다.

Firebase 비용은 인증 MAU/이메일·서버 호출/CPU·기록 읽기/쓰기·저장·전송·백업으로 분리한다. Functions 사용에는 Blaze/결제 계정 준비가 필요할 수 있으며 사용자가 결정한다. 예산 알림은 강제 지출 상한으로 보장하지 않는다. AI API·광고·추적 분석 SDK는 도입하지 않았다. [Firebase 요금/플랜](https://firebase.google.com/docs/projects/billing/firebase-pricing-plans), [제품별 계산](https://firebase.google.com/pricing).

## 실제 기기 완료 기준

- 작은/보통/큰 Android와 iPhone: 세로 화면, 200% 글자, 키보드·노치·하단 제스처, 무료 시작/선택/구매 안내 잘림 확인.
- 1~3탄 각 3회 및 15탄 전체: 무료 공략·실패→재도전·결과→해금, 드래그 순간 이동 없음·감도·손가락 가림, 보호막 실제 2초/10초, 예고·히트박스·적탄 구분.
- 저사양 포함 15분 이상: UI/raster 프레임 시간·지속 메모리·입력 지연·발열·배터리·백그라운드/잠금·강제 종료 검사. debug/에뮬레이터 FPS를 제품 성능 수치로 홍보하지 않음.
- 같은 ID 업데이트 전후: 클리어/해금/최고점수·손상 사본 복구·저장 오류 안내. 기기 기록과 서버 동기화 상태를 따로 확인.
- 유료 조합: 스토어 검증→선택→실제 사격/장갑/스킬 적용→만료 무료 복귀. 가격/상태가 미연결인 현재 빌드에서 결제를 성공한 것으로 촬영하지 않음.
- 협동: Android↔iOS 양쪽 영상/동일 tick, 지연50/150/300ms·손실·백그라운드·재접속 경계·중도 이탈·계정별 결과와 중복/서버 재시작 검사.

현 장비에서는 Windows 호스트/Android 에뮬레이터만 확인할 수 있다. Mac/Xcode·iPhone·두 실기기·실제 망·장기 발열 검증은 미실행으로 남긴다. 초기 출시에는 싱글을 우선하고 협동은 위 조건 충족 뒤 포함할 것을 제안한다.
