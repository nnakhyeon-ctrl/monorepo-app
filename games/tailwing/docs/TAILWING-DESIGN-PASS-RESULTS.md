## 자산·품질·출처

- 초상2+전투 기체2+홈 탑승2 = **6장 모두 연결**. `assets/tailwing/{rabbit,turtle}_{portrait,ship,hero}_v2.png`,각1024×1024 RGBA. 과거512px 파일을 보간 확대한 것이 아니라1254px 생성 원본을1024px로 축소했다. 원본/이전 파일은 보존했다.
- [초상 프롬프트·기존 자체 원본](tailwing/design-pass-01/ART-JOBS.json),[탑승 프롬프트·참조/생성 경로](tailwing/design-pass-01/MOUNTED-ART-JOBS.json),[규격/SHA-256](tailwing/design-pass-01/ASSET-INVENTORY.json). 내장 imagegen 사용. 참고 상용 이미지의 추출·트레이싱·이미지 조각 합성은 하지 않았다. 법적 독점성/상표/최종 상업 이용 조건은 별도 미확인이다.
- 새 PNG6장 합계7,102,894바이트. 홈은 표시폭×DPR에 따라512~1024 디코드,큰 선택 초상512/탑승768,작은 카드256. 전투는74×74 논리 크기에 맞는256 디코드를 유지한다. 모든12종을1024 전투 텍스처로 상주시켜 메모리를 늘리지 않았다.
- 음악은 [자체 PCM 생성 코드](../tool/make_tailwing_audio.dart),[파형 수치](tailwing/design-pass-01/AUDIO-CHECKS.json). 외부 샘플/상용 곡을 사용하지 않았다. mono22,050Hz/16bit,1,512,044바이트,peak0.294/RMS0.0526/클리핑0/루프 양끝0. 수치 검사는 주관적 음질·장시간 피로도 평가가 아니다.
- 나머지10종·배경·적/보스의 기존 자체 자산과 모든 식별자는 유지했다. 이번 참고 이미지의 판타지 인물/용/보스/구체적 연출·로고를 그대로 추가하지 않았다.

## 수치·데이터·권한 보존

갑판은 **3초/대기13초/일반탄5회**,전방 폭70·앞20~60 범위와 아래 방향으로 날아오는 차단 가능 일반탄만 처리한다. 측후방/보스탄/기체 충돌을 막지 않는다. 새 HUD/선은 보호막 판정을 부여하지 않는다. 기본 무료 보호막과 구독 고유 기술은 별개다.

스킬 피해/시간/재사용·피격 반경/74×74 표시 중심·적 AI/탄속/스폰·보스 시점/스테이지 규칙을 변경하지 않았다. 새 진행 안내는 추가 보상/새 웨이브를 가장하지 않는다. 저장 schema·앱/상품/콘텐츠 ID·계정 경계·월/연 혜택·무료 토끼/여우/거북이와 기본 사격/보호막·구매 잠금을 유지한다. 유료 이용권이나 가짜 구매 성공을 추가하지 않았다. 조종/진행/계정 백엔드를 새로 만들지 않았다.

## 성능·미검증

전투 자산 디코드4,462,592바이트로 기준과 동일. 선택/홈 포함 Flutter 이미지 캐시의 관측값16,699,904바이트. 짧은 debug 가상 기기 표본178프레임 중 build16.7ms 초과64/raster초과20이 있었다. **60fps/실기기 성능 통과가 아니며** 컴파일/캡처/검사 부하가 포함된 이 수치로 출시 성능을 추정하지 않는다. 새 interactive APK 시작도11.771초로 관측됐다. 실제 폰 profile/release 장시간·입력 지연·발열·저사양·고해상도 캐시 최대치를 별도 확인해야 한다.

이번에 전체15탄/보스/결과를 실시간으로 다시 완주하지 않았다. 이전 무료1탄273초 자동 조작·보스/결과/재도전 native 기록은 당시 소스의 이력으로 보존한다. 이번 전투 변경은 표시/음악이며 관련 결과/재도전/기술 만료는 가상 모델·위젯 검사와 짧은 native 흐름으로 확인했다. iOS/Mac/Xcode/iPhone·실제 스피커 청취·음악 취향/장기 유지율·밸런스 장시간 검증은 미검증이다.

실제 로그인/서버/스토어·공개 계정 삭제 웹·상품 ID/공개 주소·Apple 유료 멤버십 없음/iOS·물리 기기·보안 경고5개는 [기존 후속 결과](TAILWING-FOLLOWUP-RESULTS.md)와 [실행/설정 안내](TAILWING-RUN-GUIDE.md)에 남아 있다. 이번에 의존성/백엔드/콘솔을 바꾸거나 그 통과를 새로 주장하지 않았다.

## 직접 확인·11/12단계 영향

1. [실행 안내](TAILWING-RUN-GUIDE.md)에 따라 개발 APK를 본인 Android 테스트 기기에 **install-r**한다. 서명 불일치 시 제거/초기화하지 말고 멈춘다. 이번에 실행한 전용 가상 기기는 검사 후 종료했으며 새 실행은 직접 시작한다.
2. 홈 무료 토끼/거북이 선택→출격·기본 사격/보호막을 확인한다. 홈 아래 ‘개발 연구소’에서12종 고유 기술을 무기록으로 시험한다. 일반 앱의 구독 잠김은 정상이다.
3. 환경설정에서 배경음 미리 듣기/음량/끄기,전투 일시정지/복귀,효과 감소를 확인한다. 실제 폰 프레임/발열·음악 청취 결과를 기록한다.

11단계는 이번 영향 범위만 재검사했으며 실제 서비스/장비 대기가 남아 최종 완료가 아니다.12단계에는 새 아이콘/스토어 소개·공개 정책과 실제 기기 스크린샷,서명 AAB/IPA가 여전히 필요하다. 새 개발 APK와 이번 로컬 비교 자료만 갱신했고 **기존 미서명 release 검사 APK·그 정적 검사/기존20장 캡처는 이번 소스의 최종 제출 자료가 아니다.** 과금 전환/실제 청구/서버·페이지 배포/스토어 등록·공개/실사용자 삭제/commit/push를 하지 않았다. 이번 결과를 저장하고 멈추며 나머지 캐릭터의 새 디자인 확장은 자동으로 진행하지 않는다.
