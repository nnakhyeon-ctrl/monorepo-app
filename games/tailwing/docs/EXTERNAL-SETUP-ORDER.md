# 실제 연결·제출 전 직접 설정 순서

2026-10-29. 기존 등록을 재사용한다. 새 프로젝트/앱/상품·키를 임의로 만들거나 과금/배포/실사용자 삭제를 실행하지 않는다. 비밀키·암호·토큰·영수증·메일 링크는 문서/채팅에 보내지 않는다. 콘솔은 이번에 재조회하지 않았으며 아래는 소유자가 직접 확인할 안내다.

## 첫 작업 — Firebase 기존 앱 확인만 하기

접속: [프로젝트 일반 설정](https://console.firebase.google.com/project/airzero-strike-dev/settings/general). 본인 계정으로 로그인하고 상단 프로젝트가 `AIRZERO STRIKE DEV`인지 확인한다.

| 순서·화면 | 입력/확인 항목 | 확인 방법·멈출 조건 |
|---|---|---|
| 프로젝트 설정 → 일반 | 프로젝트 ID `airzero-strike-dev` | 현재 값과 비교만 한다. 새 프로젝트 생성/ID 변경 안 함 |
| 일반 → 내 앱 → Android | 패키지 `com.example.raikeopeu2026.dev` | 기존 앱 항목을 연다. 다른 패키지라면 새 앱으로 덮어쓰지 말고 차이를 기록 |
| Android 앱 → SHA 인증서 지문 | 기존 개발용 SHA-1/SHA-256 | 본인 PC에서 현재 서명과 대조. 아직 없는 release/Play 지문을 추측해 입력하지 않음 |
| 일반 → 내 앱 → iOS | Bundle ID `com.example.raikeopeu2026.dev` | 기존 등록만 확인. Team ID/인증서 임의 입력 안 함 |
| 요금제 표시/사용량 및 결제 | 기존 Spark 여부 | 보기만 한다. 업그레이드·Blaze·결제수단/청구 계정 연결을 누르지 않음 |

이 첫 작업에서는 **새 입력을 저장할 필요가 없다**. 모두 맞으면 “프로젝트/Android/iOS 일치, Spark 확인”만 기록한다. 관리자 서비스 계정 JSON·private key를 내려받지 않는다. 공개 클라이언트 설정은 기존 `config/.local-public/`를 재사용한다.
