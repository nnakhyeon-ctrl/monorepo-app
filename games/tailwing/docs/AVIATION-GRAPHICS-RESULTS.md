# 실제 항공 전투 그래픽 개선

2026-10-19 최신 요청. 대표 기체·1탄 배경·기본 효과·전투 UI를 먼저 실제 플레이에 연결한 기준 단위다. 이전 미래형 출격 준비의 기체 방향보다 최신 ‘기존 항공기/세계관 유지’ 요청을 우선한다. 다른 앱·계정/결제·게임 규칙을 확장하는 작업이 아니다.

## 실제 적용

| 대상 | 현재 적용 범위 |
|---|---|
| 대표 기체 | 기존 자체 제작 오로라의 쌍동체/프로펠러/날개/조종석을 유지한 1254px 투명 PNG. 금속 반사·명암·패널 보완. 첫 화면·선택·실제 무료 전투에 같은 이미지 사용 |
| 적/보스 | 2×2 PNG 아틀라스의 정찰기·쌍발 공격기·장갑기·4발 지휘 폭격기를 기존 3종 적/보스에 연결. 기존 보스 3개 패턴 유지, 무장 표시가 패턴에 따라 변화. 별개의 보스 외형 3종 완성은 아님 |
| 1탄 새벽 해안 | 고해상도 바다·해안/섬·수심/지형 명암. 매끄러운 왕복 반사 타일 스크롤·2개 속도 구름·기체 그림자로 거리감. 중앙 바다는 어둡고 단순하게 유지 |
| 기본 전투 효과 | 실제 발사/명중/파괴 이벤트와 연결한 발사광·짧은 섬광·8프레임 화염/연기. 보호막 가장자리·피격 파문·펄스 확장파·스킬 작동/정비 표시. 화면 전체 백색 플래시 없음 |
| 위험 구분 | 아군은 가늘고 긴 청록/백색 탄, 적탄은 어두운 테두리/밝은 핵의 주황 원. 예고는 점선/원호. 폭발·구름보다 적탄/플레이어 중앙점을 나중에 그려 위험을 가리지 않음. 새 드롭 아이템 시스템을 추가하지 않음 |
| 디지털 전투 UI | 남색 패널/청록 테두리·통일 아이콘·고정 폭 숫자·장갑/점수/시간/스킬 상태·실제 보스 잔여 체력·쿨다운 진행 표시. 작은 화면은 스크롤/줄바꿈 사용 |

대표 이미지는 1탄과 같은 해안 위에 실제 선택 기체를 표시한다. 우주 배경/우주선으로 전환하거나 첨부 상용 게임의 픽셀/문구/국기를 복사하지 않았다. 벡터/세이프가드의 기존 선택 ID·자산·능력은 유지한다. 메카는 기존 코드 기반 외형에 명암을 보완했으며 고해상도 전용 아트 완료로 표시하지 않는다.

## 성능·좌표·기록 경계

- 원본 PNG 5개 약7.6MB. 전투에서 기체3종 폭256·해안720·적 아틀라스512·폭발1024·구름384로 한 번 디코딩해 재사용한다. 실제 총 RGBA 픽셀은 7,632,384바이트(약7.28MiB), 앱 전체/드라이버 메모리와 다르다. 메뉴 이미지 캐시도 별도다.
- 준비 중 요청을 합치고 마지막 자산 실패 때도 부분 이미지를 해제한다. 실패 후 재시도·화면의 이미지 오류 안내·종료 해제를 유지한다. 전투 중 파일/네트워크 로딩·새 SDK 없음.
- 효과는 최대48개, 짧은 TTL 후 제거, 보호막 중 반복 접촉은 60ms 이내 합침. 일시정지 시 효과도 정지. 효과는 게임 RNG·충돌·보상에 영향을 주지 않는 일시 정보다.
- 전투 그림은 프레임 알림으로 다시 그리고 정보 위젯은 0.1초 간격, 체력/종료는 즉시 갱신한다. 드래그 이동은 즉시 좌표/그림을 갱신한다. 이용권 변경 시 실제 현재 기체 이미지를 읽는다. 이 구조를 60fps 보장으로 표시하지 않는다.
- 기존360×600 좌표/세로 시점·상대 드래그·감도·자동 사격·보호막2초/10초·적탄/적 충돌·15탄 패턴/점수/해금은 유지했다. 기체/적 이미지는 시뮬레이션 위치를 중심으로 그리며 플레이어 외곽 원은 기존 적탄 충돌 거리10을 표시한다.
- 저장 schema/앱 ID/구매 경계·동의/분석 설정 변경 없음. 효과/프레임 측정은 계정/진행 저장에 넣지 않는다. 기존 아트·F5·lockfile을 유지한다. 실제 사용자 기록/비밀번호/토큰/영수증을 읽거나 출력하지 않았다.

## 검증

- 정적 분석 문제 없음. 호스트67개(기존63+새4개) 통과. 15탄 무료 자동 공략·저장/재시작·권한·설정·조작/결과/재도전 회귀 유지.
- 새 검사는 효과 유무의 동일 시드 전투 결과·효과 수/TTL/일시정지·실제 보호막 충돌, 마지막 이미지 로드 실패 원복/재시도·RGBA 예산/투명도/아틀라스, 실제 PNG 렌더링 위의 적탄 핵/중앙점 픽셀, 320폭/글자200% HUD·보스50% 표시를 확인했다.
- 최적화 후 Android 에뮬레이터 통합5개 통과(기존4+새1). 실제 PNG/아틀라스·동시 적/보스/효과·HUD·드래그 즉시 좌표 변경·실제 보호막 충돌을 시험했고 기존 선택 저장/재시작/권한 재확인/출격·클리어/해금/재도전·소리/설정 저장도 통과했다. 그래픽 동시 표시 검사의 조우는 가상 배치이며 실제 스토어 이용권이나 사람의 난이도 검증을 뜻하지 않는다.
- 물리 기기/iOS·발열/장시간 배터리·입력부터 화면까지의 지연 측정은 미검증이다. 연결된 시험 장비는 API37 에뮬레이터다.

에뮬레이터 디버그·가상 조우에서 준비10프레임 이후 FrameTiming 129개 관찰: raster P50 5.95ms/P95 13.30ms, build P95 27.59ms, 관찰 효과 최대6개. 최적화 전 별도 관찰은 128프레임/raster P95 15.44ms/build P95 41.49ms였으나 엄격한 동일 부하 벤치마크는 아니다. 디버그 build P95가 16.7ms를 넘으므로 실기기60fps 검증 완료로 표시하지 않는다. 다음 성능 판정은 Android/iOS 물리 기기의 profile/release에서 3~5분 전투·발열·배터리/입력 반응을 함께 확인해야 한다.

최종 lib/main.dart 일반 Android x64 디버그 APK 빌드 성공. metadata의 기존 앱 ID를 확인한 뒤 install -r로 업데이트·정상 실행했다. 일반 앱에서 첫 조작 안내(이동→사격 확인→보호막), 실제1탄 자동 사격/격추·보호막 재사용·일시정지·진행 손실 확인/홈 복귀를 직접 확인했다. 녹화 후 장갑3/3·점수400/격추4의 진행 중인 전투를 확인하고 홈 복귀로 이번 전투를 종료했다. 완료 기록을 덮어쓰거나 앱 데이터를 초기화하지 않았다.

명령(앱 폴더/PowerShell):

```powershell
flutter --suppress-analytics analyze --no-pub
flutter --suppress-analytics test --no-pub --reporter expanded
flutter --suppress-analytics test integration_test/screen_flow_test.dart -d emulator-5554 --dart-define=AIRZERO_INTEGRATION=true --no-uninstall --no-pub --reporter expanded
flutter --suppress-analytics build apk --debug --no-pub --target-platform android-x64 --target lib/main.dart
```

통합 검사는 별도 .integration 앱 ID와 가상 기록/이용권을 사용한다. 일반 앱 삭제/데이터 초기화 없음. 프레임 통계는 시험용 숫자만 로컬 출력하며 추적 SDK나 사용자 로그 수집 기능을 추가하지 않는다.
