# 2인 협동 시험 구현과 운영 경계

2026-10-19. `lib/game/combat_model.dart`와 실제 전투 엔진을 Flutter 없이 사용할 수 있게 분리했다. `server/coop_server.dart`는 같은 엔진의 두 기체와 적·탄환·피격·보호막·공동 점수를 단일 권한 서버에서 계산한다. 앱은 위치/체력/명중/점수를 보내지 않고 순번이 있는 이동량·스킬 입력만 보낸다. 20Hz 입력/스냅샷, 입력 이동량 제한·순번 재연 거부·방 2명 상한·8자리 무작위 초대 코드·세션별 재접속 토큰·프레임/방/접속 수 제한을 사용한다. 초대 코드는 계정 인증을 대신하지 않는다.

## 로컬 확인 범위

`flutter test test/coop_test.dart --reporter expanded`는 loopback 서버와 실제 WebSocket 클라이언트 두 개로 방 만들기→참가→양쪽 준비→방장 시작→각자 이동/보호막→같은 tick의 동일 상태→연결 끊김 시 정지→재접속→중도 이탈 종료를 검사한다. 미준비 시작·세 번째 참가자·중복 순번·잘못된 스냅샷도 거부한다. 한 기체가 격추돼도 다른 기체로 보스를 격추할 수 있으며 두 기체가 모두 격추되면 실패한다. 서버는 결과 종료를 한 번만 전송한다.

```powershell
# 앱 폴더에서 실행. 로컬 개발용이며 공개 서버가 아니다.
dart run server/coop_server.dart
```

기본 주소는 `ws://127.0.0.1:8787/coop`, 바인딩은 PC loopback뿐이다. 외부 휴대폰용 서버를 생성/배포하지 않는다. 이 평문 주소는 호스트 간 테스트용이고 앱 클라이언트에 허용하지 않는다. Android/iOS 앱은 빌드 시 지정한 `COOP_URL`이 `wss://호스트/coop`이고 정상 OS 인증서를 통과해야 연결한다. 인증서 검증 우회·cleartext 허용·방화벽 완화는 없다. 기본 `COOP_URL`은 비어 있어 화면은 ‘협동 서버 설정 대기’다.

연결이 끊기면 양쪽 전투 시간을 정지하고 최대 15초 내 기존 재접속 토큰으로 복귀한다. 앱은 백그라운드에서 연결을 닫으며 돌아온 사용자가 재접속을 누른다. 시간이 지나거나 나가기를 선택하면 중단한다. 종료/재접속 실패를 클리어로 처리하지 않는다. 토큰은 메모리에서만 보관하고 로그·파일·분석에 쓰지 않는다. 방은 최대 10분이며 프로세스 종료 후 복구되는 서버가 아니다.

## 운영 전 필요한 구현·검증

현재는 **무료 기본 구성만** 사용하는 로컬 참고 서버다. 협동 유료 캐릭터/장비는 검증된 서버 이용권 adapter를 연결한 뒤 허용해야 한다. 게스트 협동의 보상·계정 진행 반영은 아직 실행하지 않는다. 결과에는 `rewardCommitted: false`를 보내며 싱글 진행/구매 권한을 갱신하지 않는다. 1회 종료 알림 검사는 영속 보상 중복 방지 완료를 뜻하지 않는다.

운영에는 검증된 로그인 또는 게스트 세션 소유권, 초대 코드 탐색 제한, TLS 종단, 앱/환경 분리, 비정상 프레임 차단, 영속 `(app, environment, runId, verifiedUID)` 결과 트랜잭션·재조회/ACK, 사용자별 해금·보상 기준이 필요하다. 서버가 강제 종료돼도 이미 지급한 결과를 다시 지급하지 않도록 원장과 outbox를 함께 검증해야 한다. 클라이언트 제출 점수나 원본 영수증 로그는 쓰지 않는다.

현재 보간/예측과 지연 보상은 구현하지 않았다. 스냅샷 간 이동은 20Hz이므로 싱글 60Hz 렌더와 동일한 부드러움을 보장하지 않는다. Wi-Fi/모바일망·지연 50/150/300ms·손실·순서 역전·중복·15초 경계·잠금/백그라운드·앱 강제 종료·재접속 탈취 방어를 검증한다. Android와 iOS 두 실기기에서 각자 캐릭터/적/탄환/체력/스킬/결과가 같은지 영상과 tick 증거를 남기기 전에는 완료로 표시하지 않는다.

초기 출시에는 검증된 싱글을 우선하고 협동은 비공개 개발 기능으로 유지할 것을 제안한다. 실제 기기 검증과 운영 예산이 충족되면 사용자가 포함 여부를 결정한다. 비용 가정과 서버 사전 준비는 [RELEASE-READINESS.md](RELEASE-READINESS.md)에 있다.
