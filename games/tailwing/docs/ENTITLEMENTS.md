# 무료 기본 플레이·월간/연간 프리미엄 구독

2026-10-29 사용자 확정 보완: **토끼(pilot)·여우(rion)·거북이(eden) 3종과 기본 사격/보호막은 무료**다. 월간/연간 동일 혜택 구독은 12종 전체 선택과 캐릭터별 `signature` 고유 기술·기존 추가 기체/스킬/장비를 검증된 기간에 제공한다. 무료 3종의 기본 공격/장갑 특성은 유지하지만 고유 기술은 구독 전용이다. 개구리는 호환 ID `tw_chameleon`을 사용한다. 신규 개별 판매·가격/상품 ID 확정·모의 권한의 release 적용은 하지 않았다. 현재 상품/실서버 미설정으로 구매는 잠겨 있다. [실제 적용/검사](TAILWING-ROSTER-RESULTS.md)가 아래 이전 카탈로그 수량/설명보다 우선한다.

2026-10-28 최신 10단계 구현은 [구독 구매·복원·검증 결과](BILLING-RESULTS.md)를 우선한다. 공식 Flutter 네이티브 브리지와 기존 Firebase 서버에 검증/소유권/알림/상태 처리를 연결했으며 상품 ID/가격·실제 스토어/서버·Sandbox/장비 검증은 대기다. [설정 준비](BILLING-SETUP.md)를 따른다. 아래의 “10단계 구현 대상/adapter 미연결”은 이전 정책 설계 이력이다. 기존 Dart 정책 구성요소는 검사 이력으로 보존하며 실제 서버 경로는 TypeScript/Firebase를 사용한다.

2026-10-19 실제 전투의 무료 보호막·유료 선택 능력이 구현됐다. 서버 상태 정책 구성요소는 `server/entitlement_ledger.dart`, 운영 앱 기본 adapter는 계속 미연결이다. 가상 검증 응답의 pending/failed 신규 지급 거부·취소/유예 남은 기간·만료/철회·중복/역전·타 앱/계정/스토어 거부를 검사했으며 실제 영수증 검증/복원 완료가 아니다. 월간/연간 동일 혜택과 관리자 가격 설정 대기를 유지한다. [실행 결과](PLAYABLE-RESULTS.md), [외부 준비](RELEASE-READINESS.md)를 따른다.

2026-10-18 최신 사용자 요청은 기존 1회 구매 계획을 대체한다. 기본 플레이는 무료로 제공하고 추가 기체·스킬·캐릭터·특수 장비/강화 효과는 유효한 구독으로 이용한다. 월간·연간을 모두 제공하며 두 기간의 혜택은 같다. 무료 이용은 자동 유료 전환 체험이 아니다.

## 범위와 가격 관리

| 구분 | 제공/접근 기준 |
|---|---|
| 기본 무료 | 토끼/여우/거북이 3종·기본 기체/무장/조종·일반 스테이지·사격/보호막/회피·진행/점수 기록. 로그인·결제수단 등록·구독 없이 기본 로컬 플레이 |
| 프리미엄 월간 | 전체 12종·각 종 고유 기술·기존 선택형 강화 스킬/추가 기체/반복 장착형 장비 카탈로그를 공식 유효기간 동안 이용, 1개월 갱신 |
| 프리미엄 연간 | 월간과 동일한 혜택, 1년 갱신. 실제 연간 총 청구액을 표시하며 월 환산액만 크게 표시하지 않음 |
| 기록 동기화 | 같은 앱 계정·서버 저장 완료가 필요. 무료/구독 공통, 별도 동기화 상품 없음 |
| 제외 | 광고·유료 재화·확률형 뽑기·생명/플레이 횟수 판매·무료 체험 자동 유료 전환·강제 구독 |

가격은 관리자인 사용자만 최종 검토한 후 Apple App Store Connect·Google Play Console의 관리자 권한으로 설정/변경한다. 현재 가격·할인·임의 금액은 정하지 않았다. 일반 사용자·앱 클라이언트·AI가 가격을 쓰는 기능은 만들지 않는다. 로그인 계정이 있다고 가격 변경 권한을 주지 않는다. 현재 앱에는 관리자 화면·관리자 인증·가격 변경 API도 없다.

실제 청구 가격의 기준은 해당 스토어 상품/base plan이다. 앱은 공식 SDK에서 지역화한 가격·통화·과세 표시·총 청구 주기를 읽어 보여준다. 화면 문구나 원격 DB의 숫자만 바꿔 청구 금액을 변경하지 않는다. 상품/가격을 가져오지 못하면 가입 결제를 시작하지 않고 기본 무료 경로를 유지한다. 콘솔 관리자 권한·MFA·변경 검토/이력·기존 구독자 가격 변경/동의 요구는 사용자가 공식 절차로 관리한다. 이 작업에서 콘솔 등록·가격 변경·상품 생성은 실행하지 않는다.

## 구독이 제공할 지속 가치

구독 기간에 재사용 가능한 기체·스킬·캐릭터·특수 장비 카탈로그 접근과 지속적인 콘텐츠 개선을 제공하는 계획이다. 일회성 코인이나 소모성 부스터 한 번 지급만으로 구독을 구성하지 않는다. 실제 콘텐츠 종류·업데이트 일정/분량·운영 예산은 관리자 최종 검토와 출시 전에 확정해야 하며 현재 UI 구성안이 납품 약속은 아니다. 무료 기본 구성으로 일반 콘텐츠를 정상 진행할 수 있는지 밸런스 검증한다.

이 설계는 지속적인 가치를 요구하는 [Apple 구독 지침 3.1.2](https://developer.apple.com/app-store/review/guidelines/#subscriptions)과 [Google 구독 정책](https://support.google.com/googleplay/android-developer/answer/9900533?hl=en)에 맞추기 위한 계획이며 심사 통과를 보장하지 않는다.

## 스킬·강화 기능 선택 규칙

기본 비행·기본 사격·회피·일반 진행/기록은 무료다. 변신/집중 사격/스페셜 같은 선택형 강화 스킬, 추가 아이템·전술 캐릭터의 고유 효과, 공격/장갑/쿨타임 같은 강화 모듈의 효과는 유효한 구독일 때만 적용한다. 기본 무료 조작/접근성까지 구독으로 잠그지 않는다.

누구나 콘텐츠 구성안/설명을 볼 수 있지만 미확인·미구독·만료 상태의 사용/장착/스킬 발동/강화 효과 적용은 거부한다. 현재 앱은 미연결 상태라 모두 잠금/준비 안내만 제공한다. 이후 게임에서는 장착·출격·스킬 입력·보상 정산 때 같은 권한 기준을 적용하고 서버 API는 클라이언트의 선택/premium 표시를 신뢰하지 않는다. 구독이 끝나면 효과를 해제하고 기본 구성으로 돌아가며 저장된 레벨·강화 이력은 삭제하지 않는다.

## 서버 검증과 중복 가입 방지 — 10단계 구현 대상

1. Apple은 하나의 구독 그룹에서 월간/연간 동일 서비스 수준, Google은 동일 혜택 구독의 월간/연간 base plan으로 준비한다. 전환은 공식 교체/업그레이드/다운그레이드 흐름으로 처리하고 같은 혜택을 중복 청구하지 않는다.
2. 기본 무료 기능은 로컬에서 이용한다. 구독 거래는 정식/필요한 임시 인증 세션의 소유권을 서버에서 검증하며 이메일 문자열로 소유자를 합치지 않는다. account 연결 값에 이메일·실명을 넣지 않는다.
3. 스토어 결제 결과·거래/원거래·상품/base plan·앱·환경·소유 귀속·공식 구독 상태/만료·유예·철회를 서버의 공식 API/서명으로 확인한다. 취소·PENDING·통신 실패를 활성 구독으로 처리하지 않는다.
4. 검증된 거래를 멱등 반영하고 Google 최초 구독 acknowledge 및 Apple 거래 완료를 공식 기한/상태에 맞춰 재시도한다. 단순 갱신과 신규 거래의 처리를 구분한다. 구독을 consume하지 않는다.
5. Apple Server Notifications V2·Google RTDN은 서명/전달 주체 확인 후 공식 상태를 재조회한다. 중복/지연/순서 역전·응답 유실을 처리하며 클라이언트의 premium=true나 기기 시각을 권한 근거로 쓰지 않는다.

서버 데이터는 appId·환경·스토어·상품/base plan·소유 UID·원거래/중복 방지 키·공식 상태·expiresAt·graceUntil·autoRenewEnabled·revokedAt·검증 시각/버전을 최소로 분리한다. 실제 토큰·영수증·비밀 키는 로그/공개 파일/AI 대화에 넣지 않는다. 가격·잔액·UID를 요청 본문만으로 신뢰하지 않는다.

유예 일수를 앱에 고정하지 않는다. [Play 구독 생명주기](https://developer.android.com/google/play/billing/lifecycle/subscriptions)와 [Apple 구독 상태](https://developer.apple.com/documentation/appstoreserverapi/status)를 따른다. 만료 때 저장된 프리미엄 장착은 기본 구성으로 안전하게 대체하되 해금/성장 이력을 지우지 않는다. 진행 중 만료를 확인하면 체크포인트를 보존하고 기본 구성의 재출격 경로를 안내한다. 재구독은 검증 후 기존 기록에 이어 적용한다.

오프라인 기본 플레이는 계속 가능하다. 프리미엄은 서버 서명 캐시의 공식 유효기간/검증 기한 안에서만 허용하는 안이며 구체 오프라인 한도는 10단계에서 검증한다. 앱이 임의 유예를 만들거나 알 수 없는 상태를 활성 구독으로 처리하지 않는다. 기록 동기화와 구독 상태는 별개로 표시한다.

## 복원·구독 관리·삭제

복원은 같은 스토어 계정의 기존 구독을 재검증하는 동작이며 신규 구독이나 중복 청구를 만들지 않는다. 기록은 별도로 같은 앱 UID 서버 저장본에서 불러온다. 타 앱·환경·소유자 거래는 거부한다. 다른 OS/스토어 간 이용권 공유와 이미 다른 UID에 귀속된 거래의 이전은 10단계에서 검증하며 자동 합치지 않는다.

설정/구독 화면에 공식 스토어 구독 관리 경로·해지 안내·복원·지원·약관·개인정보를 제공한다. 자동 갱신 중단과 즉시 계정 삭제는 구분한다. 계정 삭제 전에 구독 관리 방법과 잔여 결제 영향을 설명하고, 해지나 만료까지 삭제를 강제 지연하지 않는다. 삭제 후 재설치 복원·원장의 최소 보관 근거·소유 재귀속은 9/10단계에서 검증한다. 현재는 모든 실제 결제/서버 SDK가 미연결이고 구독 성공·혜택 지급을 흉내 내지 않는다.
