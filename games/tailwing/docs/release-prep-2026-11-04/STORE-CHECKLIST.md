# 직접 스토어 확인표 — 현재 제출 보류

모든 항목은 소유자가 직접 준비/확인한다. 체크되지 않은 항목은 미완료다. 현재 Google Play 게시 시점은 그래픽/기능 편집에 만족한 이후다.

- [ ] 최종 그래픽·스킬·기능 범위 결정. 13단계 변경 목록/영향 검증 갱신.
- [ ] 기존 앱 ID/업로드 키/스토어 서명과 버전/빌드 번호 확인. 현재 0.1.0+1을 최신 제출 가능 번호라고 가정하지 않음.
- [ ] 실제 운영 백엔드·Auth/App Check·이메일/Google/Kakao/필요한 Apple 연결/콜백·삭제 worker와 접근 통제 확인.
- [ ] 공개 지원·개인정보·이용·외부 계정 삭제 HTTPS URL, 본인 확인/처리 상태/보관 예외 확정. 로컬 HTML만으로 충족했다고 하지 않음.
- [ ] 법적 운영자·연락처·판매 지역/등급/대상 연령·국외 처리/SDK/보관 기간/삭제 정책 확정.
- [ ] 심사용 접근 계정/방법을 소유자가 안전하게 준비. 채팅/Git에 비밀번호를 넣지 않음. 미제공 로그인/구독 때문에 심사자가 막히는 흐름 해결.
- [ ] 실제 상품/지역별 가격·월/연 동일 혜택·갱신/취소/환불/구매 복원·계정 귀속 검증. 임시 해금/가짜 성공 금지.
- [ ] Android SDK·서명 release 연결·서명 AAB 생성/서명 지문/SHA/manifest/target API·권한/네트워크/16KB·실제 설치/콜백 검증.
- [ ] Mac/Xcode·서명/프로파일/Archive/IPA·실제 iPhone·Sandbox가 필요한 경우 준비. Android 이미지를 iOS 화면으로 제출하지 않음.
- [ ] 최종 native 아이콘·Play 아이콘/배너·실제 최종 빌드의 가상 데이터 화면 원본 재촬영. 현재 SVG/PNG는 후보, 10월 캡처는 이력.
- [ ] Google Data safety/광고·결제·앱 접근·콘텐츠/연령 등급·계정 삭제 항목을 실제 SDK 처리와 대조. [Google 공식 안내](https://support.google.com/googleplay/android-developer/answer/10787469).
- [ ] iOS 제출을 선택하면 App Privacy·연령 등급·암호화/수출·심사 정보/구독 메타데이터를 실제 앱에 맞춰 직접 작성. [Apple 심사 안내](https://developer.apple.com/app-store/review/guidelines/).
- [ ] 알려진 개발 보안 경고와 production 최소 의존성·CI/운영 Node 환경을 확인. 정적 검사만으로 유출 없음/무결함 선언 금지.
- [ ] 소유자가 공식 내부 테스트/Play 라이선스 또는 TestFlight/Sandbox를 진행하고 실제 결과를 기록.
- [ ] 공식 테스트 후 해당 기능→11→12 재검증. 소유자가 최종 심사 제출/공개를 결정.

단계 구분: **로컬 기능/자료 준비 ≠ 서명 제출 파일 ≠ 공식 스토어 테스트 ≠ 심사/공개**. 이 작업에서는 서버·페이지 공개/스토어 콘솔 등록·업로드·테스트 배포·심사·공개를 하지 않았다.
