## 로컬 구현·검증 범위

- 서버에서 확인한 UID/환경/세대별로 게스트와 A/B의 진행·클리어·최고점수·설정·기체/스킬/캐릭터/장비 선택을 분리한다. 로그아웃은 서버 기록 삭제와 다르다. 저장된 유료 선택이나 이전 계정의 늦은 이용권 응답만으로 권한을 부여하지 않는다.
- 계정 메뉴에서 현재 상태와 이메일·카카오·Google·Apple 연결 여부를 확인하고 로그아웃·전환·탈퇴로 이동한다. SDK 로그인만으로 개인 기록을 붙이지 않고 서버 세션을 검증한다. 만료·갱신 실패 시 개인 기록/권한을 분리하며 재로그인 시 해당 계정 캐시만 복구한다.
- 탈퇴는 최근 이메일/이미 연결된 소셜 재인증 → 준비 → 명시적 최종 확인 순서다. 준비·취소만으로 삭제하지 않는다. 소셜 재인증은 동일 공급자 subject만 허용하고 새 연결/계정을 만들거나 이메일 일치로 병합하지 않는다.
- 최종 접수 시 먼저 접근을 막고 앱 전용 자료·세션·공급자 매핑·Auth 사용자를 정리한다. 가상 A 탈퇴 후 재접근·오래된 토큰의 계정 재생성을 차단하고 B/다른 앱·환경의 DB 자료를 보존했다. **운영에서는 Firebase Auth 프로젝트 자체가 이 앱 전용인지 별도로 확인해야 한다.** 공유 Auth UID 삭제가 다른 앱에 영향을 주지 않는다는 검증은 아니다.
- 응답 유실·서버 정리 실패·기기 캐시 정리 실패는 완료로 표시하지 않는다. 서버에는 해시, 앱에는 OS 보호 저장소의 확인값을 두고 이미 최종 동의한 작업만 재시도한다. 재시작·중복 실행·작업 임대·확인값 만료·비공개 maintenance 재시도를 검사했다.
- 게스트 가져오기는 원본 스냅샷과 명시적 확인을 사용한다. 계정 변경 또는 기존 로컬/서버 기록 충돌 시 양쪽을 보존한다. 최초 보관이 확인된 빈 계정 캐시에만 반영한다. 전체 전투 자동 동기화는 추가하지 않았다.
- 앱 안에 삭제 범위·복구 불가·처리 중 안내와 공식 스토어 구독 관리 링크를 제공한다. 구독과 탈퇴를 구분하고 즉시 탈퇴 선택을 막지 않는다. 실제 결제·구독 해지는 실행하지 않았다.

## 이번 재개에서 수정한 오류

1. **초기 캐시 저장 경합:** 초기 계정 보관이 쓰는 중에 전환/탈퇴 정리가 끝나면 삭제한 캐시가 다시 생길 수 있었다. 쓰기 대기열과 이전 초기 읽기/보관 완료를 모두 기다린 뒤 전환·삭제하도록 수정했다. 초기 쓰기를 의도적으로 지연하는 회귀 검사로 확인했다.
2. **탈퇴 오류 안내 누락:** native HTTP 어댑터가 계정 설정 대기·삭제 확인 오류 등을 일반 연결 오류로 바꾸던 부분을 기존 안전한 오류 목록에 연결했다. controller의 만료/최종 확인/재시도 안내를 재사용한다.
3. **소셜 재인증 검사:** 원래 토큰의 인증 시각을 임의 변경하는 대신 제어된 검사 시계와 별도 서명 fixture를 사용했다. 오래된 인증의 일반 연결은 거부하고 연결된 동일 subject의 새로운 검증만 허용하며 미연결 subject는 생성하지 않는지 확인했다. 운영 검증을 완화하지 않았다.
4. **Android 검사:** 게스트 원본/가져오기 소유자 키를 사용하도록 갱신하고 A/B 전환·잘못된 재인증·탈퇴 취소/완료·삭제 후 접근 차단을 추가했다. 두 번째 가상 가입은 실제 60초 기기별 제한을 기다린다. 서버 제한을 낮추지 않았다.
5. 최종 분석의 중괄호 안내를 정리했다. 기존 인증 화면·저장 구조를 활용했고 중복 인증 서버나 비밀번호 DB는 만들지 않았다.

## 추가 구현·외부 설정 대기

1. **무료 유지:** 기존 Firebase Spark를 유지한다. 실제 로그인 서버는 미배포다. 현재 Functions 설계의 유료 요금제 전환을 실행하지 않으므로 이메일·Google·카카오도 실제 서버 왕복 완료로 표시하지 않는다. 설정 누락을 전체 허용으로 우회하지 않는다.

3. **삭제 운영:** 준비 5분·재시도 확인값 7일의 논리 검사는 구현했다. 미완료 작업에는 TTL을 두지 않는다. 실제 maintenance worker 호출·감시·최소 기록 7일 물리 정리/TTL은 미배포다. 전용 Auth 프로젝트·보관 예외/기간·지원 경로를 검증하기 전 `AIRZERO_ACCOUNT_DELETION_READY`/`AIRZERO_ACCOUNT_CLEANUP_READY`를 켜지 않는다. 서버 비밀값을 앱에 넣지 않는다.
