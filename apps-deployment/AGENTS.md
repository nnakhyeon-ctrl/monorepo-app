# 공통 배포 참고 도구

루트 AGENTS.md를 우선한다. 현재는 환경 준비이며 배포 실행 범위가 아니다.

- 스토어 등록·업로드·테스트 배포·심사 제출·공개는 사용자가 직접 한다. 하위 스크립트·skill의 자동 처리 예시는 참고용이며 대신 실행하지 않는다.
- 앱 소스를 이 공통 도구 폴더에 만들지 않는다. 앱별 식별자·서명·환경·로그인·결제 상품을 분리한다.
- 설정 및 source 대상을 먼저 검토한다. 환경변수 전체나 비밀 값을 출력하지 않는다.
- 패키지와 lockfile을 먼저 확인한다. 현재 Flutter/ios 배포용 Node 패키지는 필요 없어 설치하지 않는다. infra/scripts는 lockfile이 없어 이후 사용 전에 별도 검토한다.
- 바뀐 JavaScript는 node --check, 셸은 Git Bash -n으로 검사한다. shellcheck는 설치·실행하지 않았으며 필수 검사를 대체했다고 하지 않는다.
